# 2026-11-13 화면 구성 전면 개편

최신 사용자 지시: 목록 제안에 그치지 않고 앱의 정보 구조·레이아웃을 재구성하고 같은 키 APK/대시보드/피드까지 배포한다. frontend-design와 ui-ux-pro-max를 사용한다. 이전 트랙/색면 보완보다 이번 화면 구성을 우선한다. 데이터·접근성·승인 원본·안전영역은 유지한다.

## 방향·자체 비평

주제는 달리기와 자신만의 픽셀 캐릭터다. 모든 화면을 동일한 흰 카드 목록으로 만드는 안은 버렸다. 홈은 출발 장면, 러닝은 현재 계기판, 기록은 달린 경로와 결과, 옷장은 캐릭터와 선택목록, 크루는 소속과 일정이라는 서로 다른 구성을 쓴다. 5개 하단 목적지·기존 Back/콜백/태그/선택 상태는 보존한다.

- 색: forest #205641/deep #173E30, canvas #F5F7F6/paper #FFFFFF, mint #E0F0E8, lime #D7F58A, route blue #2E6194. 장식clay는 미니미 주변에만. 한 영역의 강조색과 충분한 여백으로 구분한다.
- 글자: 시스템 SansSerif 한글/숫자 역할 유지. 화면 제목28sp, 구역20sp, 본문16sp, 보조14sp. 축약이나 숨김으로 큰 글씨를 맞추지 않는다.
- 형태: 버튼8dp/표면12dp,48dp+조작,헤더/본문/고정조작의독립영역. 색·테두리·카드를중첩하는대신관련내용을하나의구역으로묶는다.
- 모션: 사용자 선택에 답하는 기존짧은전환만유지. 자동입장/유리/그라데이션/가짜성과/허위목표를추가하지않는다. 실제 최신 시장 점유율/사용성 개선율 측정으로 부르지 않는다.

## 구현 우선순위와 이유

|순위|영역|새 구성|이유|
|---|---|---|---|
|P0|홈|날짜→출발 장면(제목/미니미/예보)→독립 주행동→위치 상세→예정/최근|시작 행동과 정보가 한 카드 안에서 경쟁하지 않게 한다|
|P0|러닝|상태·GPS→거리/시간/페이스→경로→옵션,하단 제어 분리|달리는 동안 읽을 값과 누를 행동을 먼저 보이게 한다|
|P0|나/기록|프로필·꾸미기 진입→기간·실제 합계→기록목록→관리|캐릭터 관리와 기록 조회의 깊이를 분리한다|
|P0|옷장|캐릭터/현재착용→분류→품목·색상 한 작업영역|선택 대상을 명확히 하고 중첩된 버튼/카드를 줄인다|
|P0|기록 상세/공유|결과 요약→지도→구간/관리,편집은미리보기→도구→속성→저장|보는 흐름과 편집 흐름을 분리한다|
|P0|크루·파티|내 소속/전체 탐색→크루의 파티 일정→파티/대화|크루가 상위인 구조를 화면에서도 드러낸다|
|P1|탐색/로그인/설정/정보|지도와 독립 조작, 선택과 안내의 위계,구역별 관리|부가 화면도 같은 읽기·조작 원칙을 적용한다|

외부 폰트/의존성/키/Rules·승인 원화 변경은 없다. 원본58ID/13슬롯/9분류/0P·데이터·FGS/runId·100m동의·프로필ACK·공유export/lifecycle/IME·저장·삭제 확인은 유지한다. 화면에 구현 상세나 검토용 비교를 넣지 않는다.

실행 검증·실제Main사진·동일키서명/게시·운영피드·휴대폰/Google/사용자시각승인을구분한다. 공개0.4.4 실제출처7d921417e63d41bac5942645f2d2a50f4e1d308a는보존한다. 새후보0.5.0-dev/code27을검증하며게시전피드를바꾸지않는다.

## 반응형·상태 기준

320dp·글씨200% 홈은 짧은 장면→전체폭 시작행동→전체예보 순서로 둔다. 고정 영역이 실제 작업영역을 가리지 않게 옷장/공유는 한 세로 스크롤과 기존 짧은 창 분기를 유지한다. 크루 문맥은 한 번, 페이지 제목은 본문이 소유한다. 기본 헤더의 실제 버전·설정은 유지한다. 정상/0건/로딩/실패/마지막 수신 상태와 재시도를 구분하며 통계는 실제 합계만 표시한다.

## 스킬 채택 판단

frontend-design의 주제·정보 흐름·자체 비평과 고유한 픽셀 캐릭터 중심 원칙을 적용했다. ui-ux-pro-max의 첫 design-system 검색은 기업용 Swiss/웹 CTA, fitness 재검색도 Feature-Rich Showcase/CTA 반복·오렌지·외부 Barlow라 앱 구성에 부적합했다. 자동 저장/덮어쓰기 없이 기존 색과 시스템 한글 폰트를 유지한다. Compose 최초 검색0건 뒤 adaptive layout 재검색의 평평한 레이아웃·재사용 원칙을 채택했다. 웹 hover/기능카드/자동모션·라이브러리 업그레이드는 채택하지 않았다. 이 검색은 현재 시장 전체의 트렌드 조사나 사용자 실험이 아니다. 원문은 검토 폴더 skill-*.txt에 보존한다.
