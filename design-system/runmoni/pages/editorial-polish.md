# Runmoni 0.9 · 목록과 탐색 위계 · 2026-11-17

frontend-design의 계획 → 자체 비평 → 구현 순서를 적용한다. 러닝을 시작하는 장면과 실제 의복/사진을 중심에 두고 목록에는 사람에게 필요한 차이를 드러낸다. 같은 크기 카드·장식 배지를 추가하는 방식으로 화려함을 만들지 않는다.

## 계획

색은 기존 six-role과 새 다크 테마의 의미 토큰을 함께 사용한다. 밝은 Chalk `#F7F9FA`, Paper `#FFFFFF`, Ink `#24343D`, Ocean `#356F78`, Mist `#E7EFF1`, Coral `#F16D55`를 기준으로 하고 실제 야간 색은 공통 Theme에서 정한다. 이 파일에서 별도의 다크 팔레트를 만들지 않는다.

한글은 Android 시스템 Sans를 유지해 사용자 글꼴/확대 설정과 자연스럽게 이어지게 한다. 크루 이름은 titleLarge, 활동 조건은 bodyMedium, 가입 상태는 labelMedium으로 읽기 순서를 나눈다. 왼쪽 정렬, 목록 안 16dp, 행 사이 자연 높이, 조작 영역 최소48dp를 유지한다.

```
[크루 아이콘] 크루 이름                    >
              [위치] 지역   [페이스] 목표
              [인원] 실제 인원
              소개 (최대 두 줄)
              [체크/관리] 가입/크루장 상태
```

크루의 지역·페이스·인원은 구분점으로 연결한 긴 문자열 대신 각각의 아이콘/텍스트 묶음으로 둔다. 작은 폭과 큰 글씨에서는 FlowRow가 묶음 전체를 다음 줄로 보낸다. 탭은 밑줄과 선택 글자 굵기로 한 단계만 강조한다. 미니미 바닥은 작은 발 디딤 그림자만 유지한다.

## 자체 비평과 수정

처음에는 모든 아이콘에 색상 박스를 두려 했으나 설정·기록·크루의 모양이 같아지고 카드 키트처럼 보였다. 크루 아이콘에만 작은 완만한 표면을 남기고 조건 아이콘은 본문과 같은 줄에 둔다. 탭은 배경 박스와 밑줄의 중복 강조를 없앤다. 상태는 색뿐 아니라 명시적인 단어와 아이콘으로 전달한다. 메타 정보의 자동 줄바꿈은 허용하되 글자 크기를 줄이지 않는다.

## 구현 범위와 검증 경계

`RunmoniEditorial.kt`의 크루 목록·공통 탭을 수정한다. 제목·지역·페이스·인원·가입/크루장 상태, 클릭 콜백과 기존 테스트 태그를 보존한다. Canvas에서 테마 색을 먼저 캡처해 야간 모드에도 유효하게 한다. 홈 앱 마크와 기록 행의 후속 반영은 Root가 공유 화면 파일에서 통합한다. 이 문서는 구현 계획/자체 비평이며 최신 시장 사용성 조사 수치나 실제 새 Android 화면 통과를 주장하지 않는다.

## 기록 결과의 후속 계획·자체 비평

결과의 큰 거리와 한 장의 경로 지도는 유지하고, 시간·페이스·경로·관리의 의미를 작은 아이콘으로 보조한다. 자동 백업과 저장 상태는 본문 행이며 별도의 상태 카드로 만들지 않는다. 구간 기록은 실제1km 소요 시간의 비율을 동일 축 막대로 보여주고 정확한 시간도 함께 읽게 한다. 구간 중 최장 양수 시간에 대한 실제 비율이며0에서 시작한다. 임의 최솟값으로 길이를 부풀리지 않고,0/음수 시간에는 막대를 만들지 않는다. 긴 막대를 ‘좋음’으로 읽는 위험을 검토해 “짧을수록 빨라요”를 명시했다. 색으로 개인 기록 향상이나 건강 상태를 추정하지 않는다.

`RunRecordScreen.kt`는 이 시각 변경만 적용한다. 원래 runId/UID/operation nonce/canonical 검증과 공유·삭제·백업 재시도·내보내기 동작 및48dp를 보존한다. 새 색은 공통 의미 토큰을 사용하고 명시적 검정·흰색을 추가하지 않는다. 대형 글씨에서 기존 결과2열→1열 규칙은 유지한다.
