# 페이지 이동과 러닝 중심 UI — 2026-11-14

사용자는 반복되는 카드와 장식 문구를 줄이고, 긴 화면은 레이어보다 페이지 이동으로 연결하길 원한다. 위젯에는 선명한 색과 읽기 순서, 균형 잡힌 여백을 적용한다. 후보는 0.6.0-dev/code28이다. 새 서명·게시 검증 전에는 공개0.5.0을 유지한다.

## 시각 원칙

런모니의 주제는 실제 달리기와 승인된 픽셀 캐릭터다. 강조는 홈의 미니미, 운동 결과의 실제 수치, 위젯의 직접 제어에 쓴다. 모든 내용을 같은 둥근 카드·색띠·큰 숫자 묶음으로 만들지 않는다. 장식용 영문 소제목, 01/02 번호, 가짜 목표·연속 달성, 빛나는 배경, 자동 등장 모션, 홍보 문구를 추가하지 않는다.

기존 forest #205641/deep #173E30, mint #E0F0E8, canvas #F5F7F6, white #FFFFFF, coral #FBE7DE와 route blue를 사용한다. 앱 전체를 어둡게 바꾸지 않는다. 한글 시스템 글꼴, 본문16sp·보조14sp, 행동48dp 이상, 버튼8dp·표면12dp 모서리를 유지한다.

본문과 목록은 읽는 방향으로 정렬한다. 헤더·푸터·키보드를 제외한 공간에 내용이 들어갈 때만 짧은 화면을 수직 중앙에 놓는다. 길어지면 자연 높이로 늘어나 스크롤한다. 위젯도 실제 호스트 높이에서 남는 상하 공간을 나누고 최종 경계를 측정한다.

표시 중인 페이지 한 곳만 안전영역·IME 여백을 소유한다. 크루 하위 페이지에서는 기본 헤더와 하단 탭을 숨긴다. 알림·위젯의 현재 runId 복귀와 종료 확인은 이 경로에서도 우선한다. 삭제·탈퇴·러닝 종료·위치 동의·계정 연결 같은 짧은 확인과 OS 날짜/시간·Google·사진 선택은 필요한 확인창/시스템 화면을 유지한다.

## 실제 데이터와 캐릭터

최근7일은 현재 시간대의 오늘을 포함한 7개 달력일과 기존 canonical 기록 목록으로 계산한다. 활성 러닝을 더하지 않고 미로딩·조회불가·캐시를 정상0회로 바꾸지 않는다. 막대는 실제 거리 비례이며 최소 높이를 꾸며 넣지 않는다. 큰 글씨나 라벨 폭 부족 시 같은 정보를 행으로 읽는다.

고정 옷장 미니미의 실제 첫 프레임 표시 후 비교 썸네일을 준비한다. 스크롤로 헤더가 사라질 수 있는 짧은 화면은 이 대기를 우회한다. 승인 원본의 얼굴·체형·8프레임, 기존58ID·13슬롯·9분류·0P·보유권·지갑을 보존한다. 원인 미확정인0.5의30초 대기 이력을 이 정책만으로 해결했다고 주장하지 않는다.
