# Runmoni Atelier · 0.8 후보 · 2026-11-16 한국 시간

사용자의 여섯 요구를 함께 반영한다. frontend-design을 실제 읽고, 옷장에서는 한 명의 캐릭터, 공유에서는 한 장의 사진이 작업의 중심이 되도록 정한다. 같은 크기의 카드·색 띠·장식 그라데이션으로 모든 작업을 나누지 않는다.

## 토큰과 흐름

- 색: Kit teal #286B68, warm white #F1F6F2, paper #FFFFFF, ink #17282A, quiet gray #637579. 옷·사진의 본래 색을 주인공으로 둔다.
- 글자: Android 시스템 한글 글꼴을 유지해 OS 글자 크기를 존중한다. 페이지 제목/행 이름/보조 상태의 크기와 굵기로 위계를 만든다. 사진 출력은 독립된 그래픽 타이포그래피이며 UI의 글씨 크기를 축소하지 않는다.
- 옷장: 고정 미니미/성별 → 분류 탭 → 작은 실제 부위 그림·이름·체크의 목록 → 해당 의복 색 선택. 마지막 아이템과 뒤로가기는 시스템 바깥 안전 영역에서 접근한다.
- 공유: 전체 사진 → 그 위의 기록·미니미 → 아래 편집 도구. 비율1:1이 기본이며4:5/9:16을 유지한다. 스타일·글씨 명도·배치를 조절한다. 사진 위 색 띠/패널/전체 그라데이션을 없애고 문자 그림자/외곽선으로 대비를 확보한다.
- 지도: 무료 MapLibre/OpenFreeMap 유지. 도시 정보는 조용하게, 경로와 러너는 읽기 쉽게. 자동 검색 실패는 지도를 막지 않으며 수동 새로고침에만 필요한 안내를 제공한다. 약100m 동의·45초 현재성은 유지한다.
- 백업: 이미 연결된 Google 계정에 완료된 요약을 자동 보관한다. 경로·포인트·옷장은 자동 업로드하지 않는다. 오프라인은 대기/재시도, 계정 전환·삭제는 UID/출처 경계로 보호한다.
- 아이콘: 굵은 한 획의 Stride R과 두 색을 사용해 런처·단색·시작 화면을 연결한다. 점/지도 핀/그라데이션을 새 장식으로 더하지 않는다.

## 자가 비평과 적용

전신 미니미를 상품마다 크게 반복하면 지금 고르는 아이템의 차이가 작게 보이고 스크롤이 길다. 반대로 글자만 남기면 고르기 어렵다. 실제 합성 이미지에서 부위를 잘라 보여주는 작은 그림과 한 개의 큰 현재 미니미를 함께 둔다. 사진의 읽기 문제를 해결하려고 다시 큰 음영 패널을 넣으면 사용자 요구와 어긋난다. 글자 자체의 대비를 두 가지로 고르고 위치와 스타일을 바꾸게 한다.

Aseprite는 스킬이 아니라 별도 제작 도구다. 공식 소스를 작업공간 안에 빌드해 실제 batch/Lua 레이어 제작·내보내기를 수행하고 실행 버전·파일 해시·원본 불변 여부를 남긴다. 원화의 얼굴·체형·8프레임은 보존하고 새 신체 조립/미승인 수영복을 넣지 않는다. 기존58ID를 재번호하지 않고 새 항목3개를 끝에 추가한다. Aseprite GUI 수작업·실기기·Google 로그인 성공은 실제 관측 없이 주장하지 않는다.

[awesome-design-md](https://github.com/voltagent/awesome-design-md)와 기존 MASTER의 내용 우선·여백·48dp 원칙을 이어간다. Google Maps 프로젝트가 없다는 사용자 답변에 따라 이번에는 키·결제·SDK를 추가하지 않는다.
