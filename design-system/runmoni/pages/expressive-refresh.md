# Runmoni 0.9 · 달리기와 캐릭터를 중심에 · 2026-11-18 한국 시간

frontend-design 원문을 읽고 계획·비평·구현·실제 화면 검토 순서를 적용한다. 최신 유행의 이용률이나 경쟁 앱을 직접 사용했다고 주장하지 않는다. Android의 다크 테마·접근성·상태 보존 원칙과 기존 awesome-design-md 분석을 제품에 맞게 채택한다.

## 작은 토큰 체계

- 밝은 바탕 Chalk #F7F9FA, 표면 Paper #FFFFFF, 본문 Ink #24343D, 보조 Slate #5B6D73, 동작 Teal #356F78, 의복과 날씨를 위한 절제한 Coral #F16D55. 실제 어두운 토큰은 테마 구현의 명암·대비 검토를 따른다. 날씨 초록/주황/빨강은 장식이 아니라 환경 상태다.
- Android 시스템 한글 Sans를 의도적으로 유지한다. 사용자 글자 크기와 기기 한글 대체 글꼴을 존중하며, 제목 28/36·본문16/24·보조14/22, 거리 숫자와 단위를 분리해 위계를 만든다.
- 바깥24dp·구역32dp·내부16dp·조작48dp 이상. 긴 화면은 페이지 이동과 자연 스크롤, 넓은 빈 공간은 내용의 그룹을 구분한다. 큰 글씨/가로에서는 장식을 먼저 줄인다.
- 색과 움직임의 주인공은 승인 미니미와 사용자가 고른 사진이다. 모든 구역을 둥근 카드나 그라데이션으로 둘러싸지 않는다.

```
홈      날짜/시각 → 미니미 + 실제 날씨 → 러닝 시작 → 환경 척도 → 실제 활동/최근 기록
옷장    현재 착용 미니미 → 분류 → 해당 부위 검색/실제 그림 목록 → 독립 의복 색
공유    사진 비율 → 한 장의 전체 사진/기록/미니미 → 사진·기록·미니미 도구 → 저장/공유
설정    계정·기록 → 화면 모드(기기/라이트/다크) → 알림·정보
```

## 먼저 비평한 결정

‘화려함’을 지표 카드·색 띠·반복 애니메이션으로 채우면 사용자가 거절한 대시보드가 된다. 원화의 색과 사진을 강조하고, 선택한 부위·현재 환경·계정 상태를 알아보기 쉽게 하는 변화에만 색과 효과를 쓴다. 단순한 앱을 복잡한 앱으로 바꾸기보다 옷장 검색·실제 정보·공유 편집의 기능 깊이를 늘린다. 화면 전환은 짧고 한 번만, 시스템 움직임 해제는 존중한다.

## 구현할 UI 개선 8개

1. 홈 환경 지수: 실제 최신 예보에서 계산한 수평 척도·점수·색·짧은 행동 문구, 산정 기준과 누락 정보 표시.
2. 전체 다크 테마: 의미별 색, 기기/라이트/다크 선택 유지, 지도·시스템 바·오류·입력·팝업까지 점검.
3. 페이지 전환과 선택 반응: 짧은 전환, 이전 페이지의 중복 조작 방지, 뒤로가기/초안 유지, 움직임 해제 대응.
4. 옷장 피팅/탐색: 한 명의 미니미·부위별 실제 그림·검색·선택 위계, 새 아이템이 늘어도 찾기 쉽게.
5. 공유 편집: 한 장의 사진과 출력 스타일을 읽을 수 있는 선택지, 명확한 도구와 글씨 명도 견본.
6. 홈/기록: 누적 거리·횟수, 거리와 단위·시간/페이스, 실제 날짜를 읽는 순서로 구분.
7. 크루/분류: 지역·페이스·인원을 아이콘과 함께 정리, 가입 상태와 선택 표시의 구분.
8. 브랜드 일관성: 홈 상단도 기존 Stride R로 통일하고 내용과 조작의 간격을 맞춤.
