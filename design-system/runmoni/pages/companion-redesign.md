# 2026-11-15 러닝 동반자 개편 계획

사용자는0.6.0의 위젯·대시보드식 숫자/색 면적과 부족한 여백·가독성을 거절했다. 이번 후보는0.7.0-dev/code29이며 공개0.6.0의 실제 APK출처9a572de8da88ef42bf740d9424b22c7fa14e17cb는 그대로 보존한다.

## 시각 방향과 비평

Chalk #F7F9FA, Paper #FFFFFF, Ink #24343D, Muted #5B6D73, Ocean #356F78, Mist #E7EFF1의6색을 쓴다. 한국어 시스템 Sans를 명시적으로 유지하며 제목24–28, 본문16/24, 보조14/20–22로 읽기 순서를 만든다. 주요 구역32dp, 내부16dp, 화면좌우24dp(좁은 폭20), 조작48dp이상을 기본으로 한다. 큰 어두운 숫자 패널·형광 라임·모든 메뉴의 색상박스와 같은 카드 반복은 이번 요구에 맞지 않는다.

홈은 날짜→미니미/실제날씨→러닝 시작→실제7일 흔적→기록/파티의 흐름이다. 미니미 주변을 열어 두고 핵심 동작 하나만 Ocean으로 강조한다. 나/기록은 기간과 실제 거리·횟수·시간을 종이 표면에서 읽게 한다. 긴 내용은 독립 페이지와 뒤로가기, 큰 글씨/IME에서는 스크롤과 고정 동작을 보존한다. 위젯은 투명 호스트 안 자연 높이의 패널, 작은 러닝 아이콘·상태·동등 크기의 거리/시간·아이콘 제어로 구성한다. 큰 빈 색상 상자나 가짜0 통계를 만들지 않는다.

## 기능 우선순위와 완료 조건

1. 닉네임 연결 실패를 Auth/프로필/예약 경로로 분리하고 실제 운영 권한 거절 여부를 확인한다. 허용되지 않은 닉네임 예약을 조용히 우회하거나 중복 이름을 연결 완료로 표시하지 않는다.
2. 서버ACK를 받은 동일AuthUID의 연결을 재실행·일시적 오프라인에도 유지한다. 캐시 연결과 이번 온라인 확인을 구분하고 다른UID/로그아웃에 기존 receipt를 적용하지 않는다.
3. 약100m 위치 공개는 시작 전에 동의·선택할 수 있고 그 선택을 같은UID에 저장한다. 실제 위치 전송은 신선한 RUNNING recorder만 하며 일시정지/종료/UID변경에는 중단한다. 대기 중 위치를 공개하거나 매번 달리는 도중 설정하도록 요구하지 않는다.
4. 기존Naver 미설정 시 저해상도 래스터 fallback만 보이는 구조를 Native vector로 교체한다. MapLibre12.0.1과 OpenFreeMap의 실제 조건/가용성을 확인한다. 계정/과금을 만들지 않으며 무료 as-is 공용 서비스의 SLA를 주장하지 않는다. 출처·제스처·오류 fallback·프레임별 미니미 marker와 오프라인 테스트 경로를 유지한다.
5. 승인v0.3 원본 두 사본을 보존하며 장비의 재질 명암/밀착/가림을 개선한다. 구형v0.4 리그 부품을 재연결하지 않는다. 기존 세트1/4/5는 승인 포즈에 새 의복 레이어로 저작·출력 검토 후 연결하고 피부 underlay가 없는 수영복2/3을 완성으로 표시하지 않는다. 새 레이어의 시각적 사용자 승인은 별도다.
6. 새 입력의 검사·실제 Android 화면·같은 키 서명·공개APK·대시보드·피드를 각각 검증한다. 기존0.6 검사와 새 검사를 합산하지 않으며 실패/수정/미확인 범위를 CHANGELOG에 기록한다.
