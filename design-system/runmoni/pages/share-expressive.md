# 0.9 공유 편집 — 사진을 먼저 읽는 러닝 포스터

`frontend-design`의 계획 → 비평 → 구현 절차를 적용한다. 공유할 한 장의 사진과 저장한 러닝 기록이 주인공이며, 편집기의 구획은 조작의 대상과 결과를 구분하는 데 사용한다.

## 토큰과 구성

- 색: Chalk `#F7F9FA`, Paper `#FFFFFF`, Ink `#24343D`, Muted `#5B6D73`, Ocean `#356F78`, Mist `#E7EFF1`. 앱의 의미 색 토큰을 사용하여 다크모드에서도 같은 위계를 유지한다. 출력 글씨 견본의 흰색/검정은 실제 공유 이미지 색을 설명하므로 테마와 별도로 유지한다.
- 글자: 한국어 시스템 Sans. 본문 16/24, 조작 이름은 semibold, 설명은 보조색. 장식용 영문 대문자·가짜 기록 수치·불필요한 배지를 넣지 않는다.
- 정렬: 사진은 가운데, 도구와 속성은 왼쪽. 좌우 24dp, 구획 24/32dp, 최소 조작 48dp. 좁은 폭·큰 글씨에서는 스타일 선택지를 세로로 펼친다.

```
뒤로  기록 공유
이미지 비율 [1:1] [4:5] [9:16]
          사진 캔버스
     선택한 도구의 조작 안내
[사진 아이콘] [기록 아이콘] [미니미 아이콘]
선택한 도구의 속성
  사진: 교체 / 확대 / 위치
  기록: 스타일 포스터 / 글씨 견본 / 배치 / 문구
  미니미: 표시 / 크기 / 배치
이미지 저장                   공유하기
```

## 구현 전 비평과 수정

처음의 동일한 둥근 카드 세 개 안은 일반적인 SaaS 카드처럼 보여 거절했다. 스타일은 실제 출력의 글자 배치를 설명하는 작고 평평한 포스터 견본으로 바꾼다. 비율은 사진 위에서 바로 바꾸고, 도구 탭은 아이콘과 짧은 용도 설명을 제공한다. 변화가 필요한 부분만 진하게 표시하여 사진 캔버스와 경쟁하는 배경 장식을 만들지 않는다.

스타일 견본의 선은 배치 설명이며 실제 러닝 수치나 렌더된 기록으로 표시하지 않는다. 출력은 기존 렌더러의 전체 사진·글씨·미니미만 사용한다. 상하단 색면과 그라데이션을 다시 넣지 않는다.

## 유지할 동작과 검증 경계

1:1 기본 / 4:5 / 9:16, CLEAN·RECORD·STAMP, 독립 기록·미니미 위치와 사진 확대·이동을 유지한다. 13/17필드 초안 복원, 선택 사진 URI, 뒤로가기, 단일 스크롤과 IME 정책, 현재 기록/UID/lifecycle 검증과 미리보기·내보내기 일치를 바꾸지 않는다. 드래그 외에도 방향 버튼으로 조작할 수 있다. 실제 Android 검사와 사용자 시각 승인은 별도로 기록한다.
