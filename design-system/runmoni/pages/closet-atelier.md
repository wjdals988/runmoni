# 옷장 피팅·탐색 — 2026-11-17

## 계획

런모니 옷장은 러닝 중의 나를 먼저 보고 옷을 갈아입는 공간이다. 승인된 원본 미니미가 유일한 큰 시각 요소이며, 상품 카드를 늘어놓는 상점처럼 만들지 않는다.

- 색: Chalk `#F7F9FA`, Paper `#FFFFFF`, Ink `#24343D`, Muted `#5B6D73`, Ocean `#356F78`, Mist `#E7EFF1`의 기존 역할을 사용한다. 다크모드에서는 같은 의미의 공유 토큰을 따른다. 품목별 배경 장식색은 추가하지 않는다.
- 글자: 한국어 시스템 Sans를 유지한다. 부위 제목은 20/28 bold, 상품명은16/24, 무료·수량·선택 보조는14/22다. 작은 영문 장식 라벨이나 가격 강조는 넣지 않는다.
- 배치: 가로24dp/구역24dp, 현재 착용 미니미와 기본형 선택을 위에서 확인하고, 밑줄 탭과 실제 부위 썸네일의 한 열 목록을 읽는다. 짧은 창은 전체 스크롤 또는 기존 좌우 피팅 배치를 유지한다.
- 사용성: 추가 품목은 목록 안의 검색으로 찾는다. 검색은 현재 부위만 대상으로 하고 탭을 바꾸면 빈 검색으로 시작한다. 결과 없음에는 입력을 지우는 행동을 제공한다. 선택된 품목은 색뿐 아니라 선·체크 아이콘·선택 semantics로 구분한다.

```text
뒤로  옷장                          재생
[실제 미니미] 현재 착용 / 남자  여자
헤어  모자  얼굴  상의  하의 …   밑줄 탭
상의                         무료 / 수량
현재 선택한 옷 이름
검색 입력
┃ 실제 부위 그림  상품명          체크
  실제 부위 그림  상품명
색상 선택                         (해당 부위)
```

## 구현 전 비평

카드 격자나 둥근 필터를 더하는 안은 이미 지적된 복잡한 옷장 문제를 반복하므로 제외했다. 검색을 고정 피팅 영역에 놓으면 작은 화면·키보드에서 목록이 줄어들기 때문에 품목 스크롤 안으로 옮긴다. 현재 착용의 반복 라벨과 품목마다 붙는 무료 배지는 줄인다. 기존 실제 프레임 자르기, 원본 픽셀, 카테고리 ID, 선택 저장·무료 정책과48dp 조작은 유지한다.

## 검증 경계

이 문서는 디자인 방향이며 실제 Android 실행·사용자 시각 승인과 같지 않다. 새 품목 수와 사용 가능 여부는 카탈로그와 실제 아트 준비 상태에서 읽으며 이 화면에 고정하지 않는다. 새 Android 검사는 검색/빈 결과/초기화와 실제 선택 상태를 확인하고, Root가 빌드·실행 및 전체 검증 기록을 남긴다.
