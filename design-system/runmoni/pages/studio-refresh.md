2026-11-11 사용자 요청: frontend-design + ui-ux-pro-max를 적극 적용한다. 기존 MASTER의 데이터·접근성·안전영역 원칙을 유지하며 이 문서의 화면 구성 방향을 우선한다. Android Compose 앱이며 웹 홍보 페이지로 재구성하지 않는다.

## 디자인 계획과 자체 비평

승인된 픽셀 미니미와 실제 달리기를 앱의 정체성으로 삼는다. 홈/프로필은 캐릭터와 낮은 트랙 모티프, 러닝은 실제 거리와 명확한 제어, 탐색은 넓은 지도, 크루는 사람과 일정의 읽기 쉬운 목록이다. 모든 화면을 동일한 카드 모음으로 만들지 않는다. 가짜 기록·성과·러너와 장식용 영어 라벨을 넣지 않는다.

- 색: canvas `#F5F7F6`, paper `#FFFFFF`, forest `#205641`, ink `#192D25`, secondary ink `#556158`, route blue `#2E6194`. mint/blue의 옅은 배경은 구역에 쓰고 coral은 오류/중요 상태에 쓴다. 색만으로 상태를 전달하지 않는다.
- 글자: 플랫폼 SansSerif의 한글 가독성과 확대를 유지한다. 제목은 bold, 본문은 regular, 수치는 tabular figures. 외부 폰트 다운로드 없이 역할별 크기·행간·정렬을 일관되게 사용한다.
- 형태: 버튼8dp·표면12dp·대화상자16dp.48dp 터치와64dp 러닝 시작. 카드는 실제 묶음에만 쓰고 중첩 카드/반복 테두리를 줄인다. 정렬은 좌측, 간격은4/8dp 단위, 내용 최대640dp.
- 움직임: 탭/선택/펼침 같은 사용자 행동에만 작은 변화. 자동 장식 애니메이션·입장 효과를 일괄 적용하지 않는다. 기존 reduced motion/미니미 정책을 보존한다.

초기 대안인 ‘진한 초록 큰 숫자 카드 반복’은 모든 탭을 대시보드처럼 만들기 때문에 버렸다. ‘보라 AI/영상 hero’ 자동 검색 결과도 러닝 앱 맥락과 달라 채택하지 않는다. 캐릭터 영역 한 곳에 개성을 두고 나머지 화면은 행동·실제 콘텐츠의 차이를 드러내는 방향으로 수정했다.

## 화면별 요구

홈·최초 로그인·나/기록·옷장·탐색·러닝·크루 목록/상세·파티/채팅·공유 편집·설정·프로필·앱정보/업데이트/라이선스·기기점검·모든 확인/입력창을 확인한다. 공통 토큰 변경의 적용과 화면별 실제 수정·실행 확인은 구분해서 기록한다. 기록 공유 진입에는 눈에 보이는 ‘공유’ 이름을 둬 발견성을 높인다.

스크롤/단일 inset 소유권·원래 Back/저장/프로필 ACK/기록 재확인·UID/포인트·무료/성별·58ID/13슬롯/9탭·100m 동의·FGS/runId·승인 원본은 보존한다. 새 서비스·키·의존성·원화는 만들지 않는다. 이전 실행 결과를 새 전체 화면 검증으로 세지 않는다.
