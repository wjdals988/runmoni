# Runmoni UI 기준

2026-11-06 한국 시간. Android Jetpack Compose 러닝 앱. `ui-ux-pro-max` 고정 revision `b7d5353e0130feb8c5574ef1251f8a1db1873ccb`의 native/Compose·접근성 지침과 기존 awesome-design-md 기준을 함께 적용한다. [출처·검색·채택 판단](../../docs/design/ui-ux-pro-max/README.md).

## 방향

러닝 시작/진행 기록, 실제 크루의 파티, 내 미니미와 옷장을 중심으로 한다. 한 화면에는 한 가지 주요 행동을 우선한다. 정보 제목→주요 값/목록→보조 안내→다음 행동 순서가 화면마다 같아야 한다. 가짜 기록·러너·경로·성과, 광고식 기능 카드·과장된 카피·반복 배지는 넣지 않는다. 승인 미니미는 기존 픽셀 원본과 렌더를 보존한다.

## 공통 규칙

- 밝은 중립 배경 `#F5F7F6`, 흰 표면, 주요 행동 `#205641`, 글씨 `#192D25`, 보조 `#556158`, outline `#748071`. 색은 역할 토큰을 재사용한다. 다크 러닝 지표의 글씨는 `#FFFFFF`/`#D6E5DA`, 라임은 제한적으로 쓴다. 시스템 dark에서도 현재는 의도한 밝은 테마를 유지한다. 신규 다크 테마 구현/검증 완료로 표시하지 않는다.
- 시스템 산세리프·한글 확대를 유지한다. 화면 제목28/36sp, 구역20/28sp, 목록16/24sp, 본문16/24sp, 보조14/22sp. 숫자에는 tabular figures. 본문 자간을 좁히거나 필수 값을 말줄임하지 않는다.
- 좌우20dp, 넓은 화면32dp. 읽기 최대640dp/대화상자560dp. 페이지 안24dp, 구역32dp, 관련 행8–12dp. 4/8dp 단위로 정렬한다.
- 버튼/입력8dp, 표면12dp, 대화상자16dp. 원형은 색 견본과 의미 있는 단독 아이콘에 한정한다. 공통 ripple/선택 semantics/disabled를 유지한다. 행동 최소48dp, 러닝 시작64dp. 긴 행동은 자연 줄바꿈과 세로 재배치로 대응한다.
- 5개 하단 탭은 같은 무게로, 선택은 아이콘/라벨/선택 상태로 표시한다. 메인 러닝 시작 버튼과 경쟁하는 항상 진한 러닝 탭 장식은 제거한다. 버전/업데이트 레드닷·확인 후 다운로드는 유지한다.
- 각 루트 화면이 status/navigation/IME insets를 한 번 소유한다. 스크롤 목록 마지막에는24dp 여유, 고정 조작은 본문 공간과 분리한다. 작은 화면/큰 글씨에서는 가로행을 세로로 바꾼다. 가로 탭의 스크롤은 의도적인 탐색이며 본문 가로 넘침과 구분한다.
- 단독 아이콘에는 이름, 장식 아이콘에는 중복 설명 없음. 제목 heading, 탭/라디오/체크/토글에는 역할·선택 상태를 붙인다. 색만으로 선택·오류를 표현하지 않는다.
- 로딩/실패/정상 빈 목록/검색0건/마지막 수신 데이터는 구분한다. 폼 값·inline 오류·재시도는 보존한다. 동의/삭제/기록저장·백업/계정복원의 의미를 짧게 하려고 생략하지 않는다.
- 새 폰트/라이브러리·웹 마케팅 효과·샘플 데이터는 추가하지 않는다. reduced motion에서는 장식 움직임을 멈추고 핵심 조작을 애니메이션에 묶지 않는다. OS 스플래시는 기존 시작 흐름을 유지한다.

|화면|우선 정보·조작|
|---|---|
|첫 로그인|로고/짧은 제목→Google→게스트, 오류와 진행 상태. 기존 사용자/복구 러닝 우회 유지|
|홈|날짜·현재시각/러닝 시작→현위치 예보·옷차림→예정 파티/최근 기록. 예보 시각·출처/실패 구분, 승인 미니미 유지|
|탐색|항상 실제 지도→근처 공개 러너 미니미·위치/공유 조작. 드래그/핀치·지도 옵션, 위치 미확인/조회 실패/빈 결과 구분|
|러닝|상태/GPS→거리→시간/페이스/속도→저장/경로. 하단 일시정지/재개/종료 고정|
|크루/파티|크루 목록→크루 상세→소속 파티→채팅. 소속/일정/거리/페이스/인원 비교, Back·삭제/탈퇴 보존|
|나/기록|내 캐릭터/옷장→기간/실제 합계→기록. 상세의 기기저장·포인트·요약백업 상태는 분리|
|옷장|닫기/재생→선택 미니미·성별→가로분류→실제 품목/색. 마지막 행 접근,58ID/13슬롯/0P·기존 선택 보존|
|설정/점검|프로필·러닝/위치·요약백업·크루계정·앱정보의 명확한 구역. 원치 않는 자동 로그인/업로드 없음|
|앱정보/내역/라이선스|실제 버전/출처·업데이트 확인/사용자 확인 후 다운로드→내역/고지. 긴 글도 스크롤/닫기 가능|
|생성/확인 대화상자|제목→명시적 필드/오류/공개범위→취소·생성/확인. 작은 화면/키보드에서 행동 접근|

## 검증

수치 대비·빌드/JVM·Android 실제 실행·스크린샷·사용자 시각 승인은 구분한다. 진행 중 BG 후보의 JVM115/Android33은 새 전체 UI의 최종 검증 수로 합산하지 않는다. 정상/오류/빈 상태와320dp·글씨200%/가로/키보드/모션축소를 확인하며 미실행 항목은 그대로 적는다. 휴대폰/Google/운영쓰기·야외GPS/Doze/OEM은 별도다.
