# 런모니0.2.1-dev — Firebase 공유 방·연결·휴대폰 점검

**실기기 검증 전 개발 후보**입니다.0.2.0-dev 이후 Firebase 공유 방과 설정 → **연결·휴대폰 점검**을 추가했습니다. 운영 Firebase 설정을 등록하고 서명 APK를 검증한 뒤 게시합니다.

- 별도 유료 Python 서버 없이 Firebase 익명 닉네임·공개 크루/파티·실시간 채팅을 연결할 수 있습니다. 방 권한/정원/공지/메시지 속도를 Firestore 규칙에서도 확인합니다.
- 익명 프로필 해제·기기 변경·재설치 후 참여 내역과 방장 권한은 복구되지 않습니다. Google 기록 백업과 별도이며 해제 전 다시 확인합니다. Firebase 방의 음성/음악 방송·실시간 GPS 공유는 후속 범위입니다.

- 방 서버의 공개 방/게스트 참여 지원 여부를 직접 확인합니다. 로컬 테스트 서버와 공용 주소 응답을 구분합니다.
- Google 계정 선택 로그인과 저장된 계정의 온라인 세션 확인을 구분합니다.
- 실제 휴대폰 설치·야외 기록·앱 재실행·GPX·두 휴대폰의 방/채팅 확인 항목을 표시하고 결과를 공유할 수 있습니다.
- 공유 내용에는 버전·공개 서명 지문·연결 결과·수동 확인 표시만 들어갑니다. 이메일·UID·토큰·GPS 경로·서버 주소는 제외합니다.
- 배포 단계에서 현재 보관 인증서/Firebase Android 설정/공용 서버를 검사하는 절차를 추가했습니다.

이 검토 빌드는 공용 방 서버와 Firebase Android 설정이 아직 연결되지 않았습니다. **Google 로그인은 비활성화 상태이며 방 서버는 설정을 완료한 뒤 이용할 수 있습니다.** 설정 화면이 추가됐다는 사실은 실제 Google 로그인·공용 서버 개설·실기기 검증 완료를 뜻하지 않습니다. [연결 안내](https://github.com/wjdals988/runmoni/blob/main/docs/CONNECTED_DEVICE_CHECKS.md)에서 소유자 설정과 빌드 절차를 확인하세요.

개인 GPS 러닝·기기 기록은 기존처럼 이용할 수 있습니다. 꾸미기는 승인된 원화와 기존 보유 내역을 유지합니다.0.1.6/0.2.0과 같은 보관 키를 사용합니다. 그 이전 키의 테스트 앱은 덮어쓸 수 없으므로 필요한 기록을 내보내고 재설치해야 합니다.

실제 Android 테스트는 클라우드 소프트웨어 AVD의 debug 빌드입니다. 실제 휴대폰·Google 계정·공용 서버 성공을 대신하지 않습니다. 서명 release 빌드는 별도 CI/인증서/해시·출처 검사 후 게시합니다.
