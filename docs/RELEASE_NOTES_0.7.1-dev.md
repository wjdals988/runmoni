# Runmoni 0.7.1-dev

실기기 검증 전 개발 프리뷰입니다. 기존 보관 키를 사용합니다.

- 러닝 캡·선바이저를 선택할 수 있습니다. 모자가 머리카락 앞을 실제로 가리고, 챙·패널·접촉 그림자가 머리 방향을 따르도록 다시 그렸습니다.
- 안경의 앞뒤 렌즈·스포츠 이어폰·워치·벨트·조끼의 크기와 원근, 팔에 가리는 순서를 정리했습니다.
- 산타·곰·골든 세트의 머리 착용면과 칼라·커프·봉제·벨트, 양말·의복의 소재 명암을 다듬었습니다. 곰은 단순화한 후드·운동복 표현이며 완전한 털 인형 원화를 새로 제작한 것은 아닙니다.
- 승인 원화의 얼굴·몸 비율·8프레임과58개 아이템 ID·13슬롯·9탭·보유 정보·무료 설정을 유지합니다. 미승인 수영복은 추가하지 않습니다.

작은 액세서리는 축소 표시에서 미세하게 보일 수 있습니다. 휴대폰·Google 로그인·야외 GPS·공개 서명 APK의 실제 실행과 사용자 시각 승인은 별도입니다. 호스트 비교 이미지는 Android 앱 스크린샷이 아닙니다. 검사·서명·게시 결과와 APK 출처는 별도 검증 기록에서 확인합니다.
