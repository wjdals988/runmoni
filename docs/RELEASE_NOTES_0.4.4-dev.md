# Runmoni 0.4.4-dev — 트랙과 선택 강조

미니미 주변에 민트·라임 색면과 클레이색 러닝 트랙을 더했습니다. 홈·프로필·시작 화면과 옷장에서 같은 미니미의 개성을 이어갑니다. 승인된 캐릭터 원화와 의복은 그대로 사용합니다.

홈의 러닝 시작 영역에는 색상 포인트를 넣고, 옷장과 화면 분류 탭에는 선택 배경과 짧은 색상 전환을 적용했습니다. 탭의 밑줄·선택 상태와 조작 영역은 유지합니다.

새 키·계정·원화·의존성·서버 규칙을 추가하지 않으며 기록·지갑·보유 아이템을 유지합니다. 기록 상세·추가 공유 테마·전면 다크 모드는 이후 작업입니다.

실제 휴대폰 검증 전 개발 프리뷰입니다. 같은 보관 서명키를 사용합니다. 휴대폰의 큰 글씨·모션 축소·Google 로그인·SNS 전송·야외 러닝은 별도 확인이 필요합니다.
