# 개발 우선순위 — 0.3 구현 이후 (2026-11-02, 한국 시간)

**개발 소스는0.3.0-dev/code12, 현재 공개 APK는0.2.1-dev/code11**이다. 크루 최상위/하위 파티·삭제, 남녀 원본 두 행×8프레임·저장, 전 아이템0P 선택 보관과 옷장/전체 정렬 개선은 코드에 구현했다. Android 재검증·PR·새 서명 APK/대시보드·새 운영 규칙 적용·실제 휴대폰 검증은 아직 대기다. [현재 검토](CREW_CLOSET_REVIEW_20261102.md) · [이어서 진행할 순서](DEVELOPMENT_CONTINUATION.md).
