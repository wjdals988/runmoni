# 런모니 0.1.1-dev — 서명된 Android 개발 프리뷰

러닝 기록을 기기에 저장하고, 로컬 서버에 연결해 크루·파티를 시험하는 첫 공개 개발 프리뷰입니다.

## 포함 기능

- 홈·탐색·러닝·크루·나 5개 탭.
- GPS 러닝 거리·시간·페이스·1km 구간, 일시정지·복구, Room 저장, GPX 내보내기.
- 로컬 FastAPI·SQLite 서버를 통한 초대 가입, 크루·파티·공지·채팅·DJ 권한.
- 동의한 파일럿의 위치 공유: 15초 갱신·45초 만료.
- 미니미 20종 아이템, 기기 마일리지 구매·장착.
- 자체 음악 파일 재생, LiveKit 음성·별도 음악 트랙과 외부 음악 캡처 코드.

## 검증과 제약

기존 코드에서 자동 검증 82개(JVM 6, API 23, 오디오 브리지 32, Android 에뮬레이터 21)가 통과했습니다. 이번 release build에서 JVM 6개와 lint(오류 0개·경고 17개), APK 서명, SDK 36 전용 에뮬레이터 설치·cold launch를 별도로 확인했습니다.

실제 휴대폰 검증은 0회입니다. 외부 지도·공용 DB·HTTPS API·LiveKit 서버는 미배포이며, 다른 기기와의 크루·위치·음성·DJ 기능은 서버 설정과 추가 검증이 필요합니다. Firebase SDK·원격 연동도 아직 없습니다. 초대 가입은 새 계정 생성 방식이며 기존 계정 복구 로그인은 후속 작업입니다.

Android 10(API 29) 이상이 필요합니다. `0.1.0-dev` debug APK와 인증서가 달라, 이전 테스트 앱을 쓰셨다면 필요한 GPX를 먼저 내보내고 제거한 뒤 설치해 주세요. 이후 공개 APK 업데이트에는 같은 release 키를 유지합니다.
