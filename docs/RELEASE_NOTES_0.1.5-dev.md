# 런모니 0.1.5-dev

이 문서는 개발 프리뷰의 변경 설명이다. 파일 존재만으로 APK 게시·실기기 검증·Firebase 로그인 완료를 뜻하지 않는다. APK의 실제 버전은 `0.1.5-dev`, versionCode는 `6`으로 준비한다.

## 화면과 미니미

- 홈에서 러닝 시작을 우선하고, 빈 통계·서버 진단 카드를 줄였다. 진단과 계정 설정은 별도 설정 화면에서 확인한다.
- 설정을 스크롤 가능한 전체 화면으로 정리하고 제목·설명·하단 탭의 글자 크기를 조정했다. Android의 사용자 글씨 배율은 유지한다.
- 러닝 중 시작·일시정지·재개·종료 조작을 하단에서 접근하도록 구성했다. 크루 가입 안내와 개인 기록 목록의 중복 표현을 줄였다.
- 미니미에 PNG 원화 부품 63개와 8프레임 달리기 애니메이션을 연결하고, 기본 러너와 특수 의상의 얼굴·체형 일관성을 개선했다. 원화 리소스와 앱 버전은 별도로 관리한다.
- 달리는 사람을 표현한 단순한 앱 아이콘을 적용했다.

## 계정·앱 정보

- Google 로그인 버튼에서 계정 추가를 지원하는 흐름을 사용하고, 계정 선택·Google 응답·Firebase 인증 실패를 고정 오류 코드로 구분한다. 원문 예외·이메일·UID·토큰을 진단 로그에 넣지 않는다.
- 선택한 완료 기록의 요약 1건을 현재 Google 계정에 백업·조회·삭제하는 기능을 준비했다. 요약은 8개 필드이며 GPS 경로 원본·꾸미기 포인트·아이템은 포함하지 않는다. 실제 사용자 로그인과 원격 백업 성공은 아직 확인하지 못했다.
- 설치 버전과 변경 내역, 대시보드·GitHub·라이선스/SDK 고지·문제 신고 진입점을 추가했다.
- 더 새로운 신뢰 가능한 공개 APK가 확인되면 버전 영역에 새 버전 표시를 제공한다. 확인 실패를 최신 버전으로 표시하지 않으며, 다운로드는 사용자 확인 후 외부 화면에서 진행한다.

## 검증 범위와 남은 확인

- 이전 `0.1.4-dev`에서 실제 Android 화면 8장과 UI 검사 38개를 확보했다. 이 결과는 새 캐릭터 렌더러의 Android 실행 검증으로 합산하지 않는다.
- 새 원화의 데스크톱 호스트 미리보기는 실제 Android 캡처와 구분한다. 호스트 검사에서 7클립·56프레임, 58개 착장 레시피와 범위 밖 정수 입력 52건을 확인했다. 실제 Android 재생·성능은 이 결과에 포함하지 않는다. 최종 빌드·서명·검사 수치는 [검증 기록](VALIDATION.md)에 실제 수행 후 기록한다.
- Firebase 공식 client API의 프로젝트/앱 설정 확인과 Google 제공자 URI 생성은 HTTP 200으로 확인했다. 사용자 인증·계정 생성·DB 쓰기는 수행하지 않았다.
- 실제 휴대폰 설치/업데이트·Google 로그인·Firestore 인증 후 백업/조회/삭제·야외 GPS·두 기기 음성/음악 동작은 추가 확인이 필요하다. AVD는 사용자 요청에 따라 실행하지 않는다.
- 크루·파티·채팅·음성/음악은 별도 파일럿 서비스의 연결과 설정이 필요하다. Google 로그인만으로 해당 공용 서비스나 위치 공유가 활성화되지 않는다.
- 코스 탐색·공개·파티 코스 브리핑은 설계를 확정한 후속 기능이다. 이번 버전에 구현·배포된 기능으로 표시하지 않는다.

기존 공개 `0.1.1-dev`에는 Firebase 계정 기능이 없다. 설정 파일을 준비하는 것만으로 기존 설치 앱이 변경되지는 않는다. 새 APK의 게시 여부와 다운로드 주소는 실제 GitHub 릴리스 및 대시보드에서 확인한다.
