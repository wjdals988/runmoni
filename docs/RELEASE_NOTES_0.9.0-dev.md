# Runmoni 0.9.0-dev

실기기 검증 전 개발 프리뷰입니다. 최신 예보의 러닝 환경 지수, 밝게·어둡게·기기 테마, 옷장 탐색과 새 의복·장비, 사진 공유 편집, 홈·기록·크루의 정보 위계를 개선합니다.

환경 지수는 기온·바람·강수 등 제공된 예보의 자체 계산 안내이며 건강·미세먼지·노면 안전을 측정한 점수가 아닙니다. 예보가 오래되거나 필요한 정보가 없으면 점수를 표시하지 않습니다. 원본 캐릭터·기록·지갑·계정과 기존 서명키를 보존합니다.

휴대폰 설치·Google 로그인/백업·운영 프로필/위치 공유 쓰기·SNS 전달·야외 GPS·제조사 절전·Android31 이상과 사용자 원화 승인은 별도 확인 대상입니다. 실제 Aseprite 제작과 호스트 이미지, Android 실행, 사용자 시각 승인을 구분합니다. 새 의상 ID의 온라인 표시에는 새 Firestore 규칙의 운영 게시가 필요합니다.
