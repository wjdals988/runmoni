# 런모니 0.3.5-dev — 시작 화면·문구 정리

기존 로고가 있는 시작 화면을 추가하고 홈·옷장·설정의 반복 설명을 줄였습니다. 연결 점검은 도움말에 모으고 앱 정보의 아이콘을 런처와 맞췄습니다. 로그인이나 서버 응답을 기다리도록 시작 화면을 붙잡지 않습니다.

기록·포인트·보유 아이템과 기존 꾸미기 기능은 유지합니다. 계정 연결·복원과 백업 범위 안내도 남겼습니다. 새 원화·Firebase 규칙·서명키 변경은 없습니다.

실제 휴대폰 검증 전 개발 프리뷰입니다. 실제 휴대폰·Google 로그인·운영 두 기기 쓰기·야외 GPS/배터리와 Android 12 이상 시작 화면 실행은 별도 확인이 필요합니다. 클라우드 API29 실행은 이 검증을 대신하지 않습니다.

APK는 이전 개발 프리뷰와 같은 보관키로 서명합니다. 업데이트는 앱 정보에서 확인 후 다운로드하며 설치는 Android에서 직접 진행합니다. 승인 원본과 36개 표시 품목은 유지하고, 미준비 22개 원화와 새 화면의 사용자 시각 승인은 별도입니다.
