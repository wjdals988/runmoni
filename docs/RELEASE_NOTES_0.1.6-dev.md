# 런모니 0.1.6-dev / code7 — 서명된 개발 프리뷰

홈·나·옷장·지도에 승인된 v0.3 기본 미니미의8프레임을 연결했습니다. 준비 중·읽기 실패·재시도를 표시하며, 아직 원화가 없는 아이템의 구매·착용을 중단하고 보유권·포인트·저장 선택을 보존합니다.

상단 버전명과 신뢰할 수 있는 새 버전의 알림 점에서 다운로드 확인으로 바로 이동합니다. 실제 다운로드는 사용자가 선택해야 시작하며, 업데이트 확인 실패를 최신 버전이라고 표시하지 않습니다.

이번 APK는 새 배포 서명키를 사용합니다. 이전 키의 테스트 설치본에는 덮어쓰기 업데이트가 되지 않아 재설치가 필요합니다. 기존 설치본에 보관한 기록이 있으면 재설치 전에 내보내기로 보존하세요.

여자 기본형·58종 의상 레이어·수영복의 실제 옷장 통합은 미완료입니다. 실제 휴대폰 설치·실행·로그인, 야외 GPS와2대 기기 음성도 검증되지 않았습니다. Google 로그인과 원격 백업은 실제 인증 검증이 남아 있습니다.

이번 출처의 GitHub Actions release 빌드·JVM31/31·lint 오류0/경고57과 실제 APK 서명/패키지/non-debuggable/내장 revision 검사가 통과했습니다. 과거 debug Android 화면 검사나 이전639b1f9 후보 결과를 이번 APK의 실기기 실행 결과로 합산하지 않습니다.
