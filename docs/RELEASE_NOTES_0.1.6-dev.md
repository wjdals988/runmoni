# 0.1.6-dev / code7 — 개발 중, 미게시

홈의 거절된 v0.4 미니미를 승인 v0.3 전신 기본형으로 복구했다. 나·옷장·지도와 같은 표시 경로를 사용한다. 원본 파일을 수정하지 않으며 기본 러닝복의8프레임을 직접 사용한다.

상단에 설치 버전명을 표시하고, 새 공개 버전이 있으면 같은 영역에 레드닷을 표시한다. 해당 영역을 선택하면 앱 정보의 현재/새 버전 확인창을 거쳐 APK 다운로드 링크로 이어진다. 일반 설정의 맨 위에도 새 버전 안내를 제공한다. 조회 실패를 최신 버전으로 표시하지 않으며, 사용자가 취소해도 확인된 새 버전의 알림은 유지한다. 실제 다운로드 선택 전에는 외부 링크를 열지 않는다.

연결/인증이 안 된 모임 목록을 정상 조회한 빈 결과처럼 표시하던 문제도 수정했다. 별도 원화 검토 화면에서 미승인 수영복과 독립 색상을 살펴볼 수 있다.

여자 기본형 선택·58종 의상 레이어는 아직 미완료다. 준비되지 않은 비기본 아이템은 구매/착용할 수 없고 보유권·포인트·선택을 보존한다. 전체 꾸미기가 완료됐다고 표시하지 않는다. 실제 Google 로그인·야외 GPS·2대 기기 오디오는 미검증이다.

현재 클라우드 빌드는 별도 로컬 테스트 키를 사용한다. 기존 공개 앱의 업데이트용 서명 APK가 아니며 대시보드 다운로드에 연결하지 않는다. 기존 릴리스 키가 클라우드에 없고 GitHub 서명 설정 조회는403이었다. 새 정식 APK·GitHub Release 자산 게시·공개 피드·대시보드 변경은 진행하지 않았다. 기존0.1.5 서명 APK의 sourceRevision은 `75c39ca900b140cfb02c1a47807a5955c8b8db7f`로 유지한다.
