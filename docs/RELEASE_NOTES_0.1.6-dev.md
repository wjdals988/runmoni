# 런모니0.1.6-dev / code7 — 미게시 후보

홈의 거절된 v0.4 미니미를 승인 v0.3 전신 기본형으로 복구했다. 나·옷장·지도와 같은 표시 경로를 사용하며 원본 기본 러닝복의8프레임을 직접 재생한다. 준비/읽기 실패/재시도 상태를 추가했다.

상단 설치 버전명과 레드닷을 선택하면 새 공개 버전 확인과 사용자 선택 APK 다운로드로 이어진다. 조회 실패를 최신 상태로 표시하지 않으며, 취소 전후의 알림과 다운로드 확인을 유지한다. 연결되지 않은 모임을 정상 조회한 빈 결과로 표시하던 문제도 수정했다.

사용자 요청으로 새 배포 서명키를 사용한다. 이전 키의 테스트 설치본에는 덮어쓰기 업데이트가 되지 않으며 재설치가 필요하다. 기존 APK의 인증서/해시/출처를 바꾸지 않는다.

여자 기본형 선택·58종 의상 레이어·수영복 옷장 통합은 미완료다. 원화가 준비되지 않은 아이템 구매/착용은 중단하고 보유권·포인트·저장 선택을 보존한다.

새 서명 후보는 clean639b1f9에서 오프라인 release 빌드·JVM31개·lint오류0/경고27·실제 APK 서명/버전/원화 검사에 통과했다. 이전 debug 빌드의 Android 기본8개·실제320dp/font2에서4개 검사는 이 서명본 실행과 별개다. 실제 휴대폰 설치/업데이트·Google 로그인·야외 GPS·2대 음성 검증은 남아 있다.
