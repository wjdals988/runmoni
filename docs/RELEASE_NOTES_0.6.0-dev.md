# Runmoni 0.6.0-dev — 페이지 이동과 러닝 중심 화면

설정·프로필·앱 정보·크루와 파티의 긴 화면을 독립 페이지로 연결합니다. 뒤로가면 이전 목록과 작성 중인 내용을 이어서 확인할 수 있습니다. 삭제·계정 연결 같은 짧은 확인은 대화상자를 사용합니다.

위젯은 짙은 녹색 바탕에 거리와 시간을 크게 표시하고 주요 제어를 라임색으로 구분합니다. 남는 높이에서 내용이 가운데 놓이도록 조정하고, 글자 확대와 실제 호스트 크기를 함께 검사합니다. 짧은 시작 화면은 여백을 나누고 긴 목록과 입력은 위에서부터 스크롤합니다.

Android10(API29)의 긴 입력 페이지에서 키보드가 올라오면 본문과 저장 버튼이 키보드 위 공간에 맞춰지도록 조정했습니다. 페이지를 닫으면 원래 창 설정을 되돌립니다.

홈에는 기기에 저장된 최근 7일의 실제 러닝을 표시합니다. 옷장은 공간에 따라 2열 비교 또는 1열로 바뀌며, 공유 이미지에는 코랄 테마를 추가합니다. 승인 캐릭터 원본과 기존 기록·지갑·아이템·위치 공유 동의를 유지합니다.

실제 휴대폰 검증 전 개발 프리뷰입니다. 같은 보관 서명키를 사용합니다. 클라우드 UI 검증과 실제 휴대폰·Google 로그인·운영 쓰기·SNS 전달·야외 러닝은 구분합니다.
