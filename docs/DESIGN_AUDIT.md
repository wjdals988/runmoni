# 디자인 감사와 반영 — 2026-10-25

## 검토 범위

RunmoniApp, RunmoniTheme, RunmoniDialogs, MapPane, MiniMi의 정적 검토와 기존 UI 테스트 17개의 범위를 먼저 확인했다. 독립 에이전트의 읽기 전용 감사 1개만 실행한 동안 다른 설치·빌드·전송은 하지 않았다. 렌더링되지 않은 코드를 보고 실제 화면 잘림을 재현했다고 주장하지 않는다.

- 코드에서 추출한 불투명 색상 9개 조합: 9/9 통과. `scripts/audit-design-contrast.py` 실행 결과.
- 기본 UI·상태 33/33, 72.071초. 기존 UI17 + 폭/글씨 디자인2 + 아바타 통합3 + 실제 재생4 + 앱 정보4 + 업데이트 제어3. `work/design-ui-final.log`.
- 실제 AVD 화면 840×1680px/density420 = 320dp, 시스템 글씨 2배: 대화상자4 + 앱 정보1 = 5/5, 18.998초. `work/design-ui-native-large-final.log`.
- 5개 탭 × 9개 폭/글씨 조합 = 45개 화면 조건, 고정 러닝 버튼 9개 조건. 핵심 버튼 최소56dp·시작64dp를 확인했다. 38개 테스트 안의 반복 조건이므로 별도 테스트 수로 합산하지 않는다.
- 큰 글씨 옷장: 9탭·장비5하위분류 선택, 고정 미리보기, 세트 착용 후 일반 상의로 해제 확인. 미리보기는 큰 글씨에서144→96dp로 줄이고 48dp 재생 버튼을 유지했다.
- 실제 재생4개는 frameOverride를 쓰지 않는 8프레임 방문·실제 픽셀 변화, 옷장 정지/재개, Lifecycle STOP/START, 시스템 애니메이션0/1을 검증했다. 정지 시 마지막 그려진0프레임 장벽과 Compose 지연 스케줄러를 함께 동기화했다.
- 업데이트: 숫자 code 비교, 신뢰 URL/인증서 메타데이터, 정식/개발 채널, 6시간 캐시·30초 재시도·중복 요청 방지·실패 후 복구, 확인 전 외부 실행0회/확인 후 정확한 APK 링크1회를 검증했다. 실제 설치 정보는 PackageManager와 UI 표시를 대조했다.
- 실제 키보드에서 입력/전송 전체 높이를 접근성의 화면 좌표로 확인했다. IME 시작y1000, 입력끝y947(53px 여유), 전송끝y918(82px 여유). 첫 뒤로가기는 키보드, 다음은 채팅을 닫으며 크루 선택이 보존됐다.
- 마지막에 Material3 기본 보라색 surfaceContainer를 브랜드 표면으로 바꾸는 색상만 정규화했다. 위 38개는 정규화 전 배치·동작 결과이며 최종 release 빌드·대비·실제 화면 결과는 VALIDATION/RELEASE에 분리한다.
- 실제 TalkBack 탐색·야외 햇빛·달리면서 터치·실기기 글꼴/제조사별 화면은 미확인.
- Firebase `runmoni-3c08e`: Android 설정 파일의 프로젝트·패키지·Web OAuth·release 인증서4개 일치와 설정 포함 빌드를 확인했다. 실제 Google 로그인·원격 CRUD·Rules 원문 대조는 미검증이다.

## 발견·수정 이력과 한계

초기 텍스트 검사에서 paragraph 전체 폭을 실제 글자 폭으로 오해한 테스트 실패를 고쳤다. 현재는 실제 각 줄의 좌우·아래 경계를 측정하고 물리 픽셀 반올림1px만 허용한다. Dialog는 CompositionLocal 글씨 배율만으로 검증하지 않고 실제 시스템 배율을 바꿨다.

처음38개 이전 통합 검사37개는34통과/3실패였다. 레드닷은 병합 semantics 탐색 문제, 시스템 애니메이션은0프레임 정착 전 캡처 문제, 채팅은 실제 키보드 가림이었다. 채팅을 Activity 내 화면으로 옮긴 후 실제 UI로 재검증했다. 테스트 조건을 줄이거나 입력/정지 검사를 제거하지 않았다.

원본 스크린샷은 `outputs/design-review/20261025/design-review`에 있다. `*-fixture-not-a-published-release`는 업데이트 알림용 합성 데이터이며 실제 게시 버전이 아니다. 최종 사용자용 스크린샷은 서명 release APK에서 별도로 캡처한다.

최종 서명 release의 실제 원본16장은 `outputs/design-review/20261025/release`에 보존했다. [화면 확인 기록](SCREENSHOT_REVIEW_20261025.md)에서 일반/320dp·글씨200%와 피드 실패 상태를 구분한다. 초기 큰 글씨 옷장은 상품이 아래에 있어 검토 중 조작 불가라는 의견이 나왔으나, 소스상 분류와 상품은 함께 스크롤되며 후속 실제 캡처에서 상품명·가격·버튼 전체의 동시 가시성을 확인해 해당 판단을 철회했다. 새 분류 제어를 만들거나 검증된 앱을 불필요하게 재빌드하지 않았다.
