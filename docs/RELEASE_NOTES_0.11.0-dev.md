# 런모니 0.11.0-dev

- 러닝 결과는 거리·시간·평균 페이스에 이어 1km 구간 차트와 표를 보여 줍니다. 구간을 선택하면 전체 평균과 직전 구간에 비해 얼마나 차이 났는지 확인할 수 있습니다. 지도는 **경로 보기**에서 엽니다.
- 홈의 **최근 7일**에서 달린 거리와 횟수, 러닝 시간을 확인하고 마지막 결과를 엽니다.
- 설정 또는 러닝 옵션에서 1km 구간 페이스 음성과 진동을 고를 수 있습니다.
- 러닝을 시작하기 전에 거리 또는 시간 목표를 하나 고릅니다. 남은 양은 러닝 화면에서, 달성 여부는 결과에서 확인합니다.

기존 배포 키를 사용하는 Android 개발 프리뷰입니다. 휴대폰 실기기와 이어폰·제조사별 절전 동작은 별도 검증 범위입니다. [결과 화면과 Android 검증 범위](https://github.com/wjdals988/runmoni/tree/main/docs/app-review/2026-11-28-run-results)
