# Runmoni 0.3.3-dev — 기본 러닝복 색상

실제 휴대폰 검증 전 개발 프리뷰입니다. 새 색상 결과의 사용자 시각 승인은 아직 받지 않았습니다.

- 승인 원본의 기본 상의·하의·신발 천 색상을 각각 바꾸고 저장합니다. 원본·민트·코랄·블루·퍼플·골드를 지원합니다.
- 원본 남녀 두 행×8프레임과 얼굴·체형을 재생성하지 않고 프레임별 명시적 의복 마스크와 명암 팔레트를 적용합니다.
- 옷장 상의·하의·신발 탭에 이름·선택 표시가 있는 색상 조작을 추가했습니다. 기본형에 적용하며 미준비 의상의 형태를 완성으로 표시하지 않습니다.
- 기존 포인트·보유권·성별·58개 아이템 ID/13슬롯/9개 탭을 유지합니다. 색상 변경과 적립이 겹칠 때 잔액 표시가 뒤처질 수 있는 경합을 보강했습니다.
- 기본 Firebase 경로의 색상은 기기 저장 범위입니다. Google 연결만으로 원본 GPS·포인트·옷장·색상을 다른 기기에 복원하지 않습니다. 선택형 HTTP 서버는 새 색상 PATCH 계약을 지원해야 합니다.

새 의상 형태·수영복·모든58종 원화 완성이 아닙니다. 실제 휴대폰·Google·운영 두 기기 쓰기·야외 GPS는 별도 미검증입니다. 기존 보관 서명키를 유지하며 새 Firebase Rules 변경은 없습니다. 호스트 출력·Android 실행·사용자 시각 승인을 구분합니다.
