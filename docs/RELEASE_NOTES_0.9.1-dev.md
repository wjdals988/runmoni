# 런모니 0.9.1-dev

러닝 위젯과 출발·꾸미기·공유 흐름을 개편한 실기기 검증 전 Android 개발 프리뷰입니다.

1. **위젯**에서 대기 중에는 러닝을 열고, 기록 중에는 시간과 일시정지·재개를 확인할 수 있어요. 넓게 배치하면 거리와 종료 확인 버튼도 표시돼요.
2. **홈**에서 미니미 옆에 러닝 환경 점수와 출발 판단을 모았어요. 예보가 없을 때는 현재 위치 날씨를 바로 확인할 수 있어요.
3. **옷장**에서 작은 화면의 피팅 영역을 줄이고, 현재 부위에 고른 아이템 이름을 피팅에 표시해요.
4. **기록 공유**에서 비율, 스타일, 사진·기록·미니미 도구를 미리보기 가까이 배치했어요.
5. **러닝 결과**에서 거리·시간·페이스와 공유를 먼저 표시해요. GPS 경로를 그릴 수 없는 기록에는 이유를 안내해요.
6. **탐색·크루**에서 지도부터 둘러볼 수 있어요. 러너 보기와 내 위치 안내는 각 버튼에서 열리고, 크루는 가입 상태에 맞는 소개 또는 다음 파티를 표시해요.
7. **업데이트**는 설정의 앱 정보와 업데이트에서 확인할 수 있어요. 새 개발 프리뷰를 선택하면 버전과 다운로드 안내가 표시돼요.

API 29 에뮬레이터에서 위젯·앱·알림의 일시정지 및 재개, 큰 글씨와 다크모드 위젯, 320dp·200% 글씨의 옷장을 확인했습니다. 새 미니미 코디는 착용 비교 시안으로 제공됩니다. [화면과 검증 기록](../CHANGELOG.md) · [착용 비교](app-review/2026-11-27-outfit-concepts/README.md)
