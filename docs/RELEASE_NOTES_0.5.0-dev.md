# Runmoni 0.5.0-dev — 화면 구성 개편

홈은 미니미와 출발 준비, 독립 러닝 시작 버튼으로 정리했습니다. 러닝은 거리·시간·페이스와 저장/권한 안내, 경로, 고정 제어를 구분합니다.

옷장은 통합 피팅 영역과 분류·품목·색상 선택으로 단순화했습니다. 크루는 소속과 날짜별 파티 일정, 기록은 결과·경로·구간/관리, 공유는 기본1:1 미리보기·도구·속성·저장 흐름으로 개편했습니다. 로그인·설정의 정보 계층도 정리했습니다.

홈 시계의 등록·해제를 화면 표시 기간과 메인 스레드에 맞췄습니다. 승인 캐릭터 원본과 기존 기록·지갑·아이템·위치 공유 동의를 유지합니다.

실제 휴대폰 검증 전 개발 프리뷰입니다. 같은 보관 서명키를 사용합니다. 클라우드 UI 검증과 실제 휴대폰·Google 로그인·운영 쓰기·SNS 전달·야외 러닝은 구분합니다. 일부 옷장 검사의 연속 실행에서 미니미 준비 대기가 초과했고, 같은 APK·같은 조건의 분리 재검사에서는 통과했습니다. 원인은 미확정이며 기록을 보존했습니다.
