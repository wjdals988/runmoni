# Runmoni0.4.2-dev — 프로필 연결 재시도·현재 위치

온라인 프로필이 서버에서 확인된 뒤 연결을 완료합니다. 닉네임 저장이 실패하면 입력과 같은 계정을 유지해 다시 시도하고, 프로필 안내를 창 안에서 보여줍니다. 프로필 연결 완료와 뒤따르는 크루 목록 조회 실패는 구분합니다. 기존 기록·포인트·보유 아이템·UID·크루 소속·Google 연결 경계를 유지합니다.

홈 미니미 옆 날씨와 탐색 지도에 현재 위치 부근의 지역명을 표시합니다. 기기의 지역명 조회가 지원되지 않으면 근처 좌표로 표시합니다. 예보 지역과 현재 확인한 위치는 구분하며 상세주소·새 공개 공유·배경 위치 수집은 추가하지 않습니다.

실제 휴대폰 검증 전 개발 프리뷰입니다. 사용자 0.4.1 연결 실패 보고를 바탕으로 수정하며 운영 Firebase Rules 버전·Google 로그인·새 버전 휴대폰 결과는 별도입니다. 운영에 닉네임 예약 이전의 규칙이 남아 있으면 소유자 콘솔에서 최신 규칙 게시가 필요합니다. 이번 앱은 권한 검사를 우회하지 않습니다. 동일 보관 서명키를 사용합니다.
