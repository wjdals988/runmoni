# 런모니 0.3.8-dev — 업데이트 표시 간격

실제 휴대폰 검증 전 개발 프리뷰입니다.

- 우상단 새 버전 레드닷과 버전 글자·설정 버튼이 겹치지 않도록 점의 공간과 간격을 확보했습니다.
- 좁은 화면의 별도 버전 행과 글자 확대를 유지하며 업데이트 상태를 버튼의 접근성 상태로 안내합니다.
- 버전 영역에서 새 버전을 확인하고 명시적으로 선택한 뒤 APK 다운로드 화면으로 이동합니다.
- 기존 기록·포인트·미니미/옷장·Google/게스트 진입·백그라운드 러닝은 유지합니다. 새 Rules·서명키·의존성 변경은 없습니다.
- 클라우드 API29의 실제 Android 픽스처 검토와 실제 휴대폰·Google·야외GPS·Doze/OEM·Android12이상·사용자 시각 승인은 별개입니다. 새 버전 표시 검토의99.0.0-dev는 합성 데이터이며 실제 공개 릴리스가 아닙니다.
