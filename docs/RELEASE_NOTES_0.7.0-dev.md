# Runmoni 0.7.0-dev

실기기 검증 전 개발 프리뷰입니다. 기존 보관 키를 사용하며 휴대폰·Google 로그인·야외 GPS와 장시간 백그라운드 동작은 별도 확인이 필요합니다.

- 화면 여백·글자 위계·아이콘과 차분한 청록 팔레트를 정리했습니다. 위젯은 밝은 패널과 거리·시간·제어 중심으로 다시 구성했습니다.
- 서버에서 저장을 확인한 프로필을 같은 계정에서 유지합니다. 일시적인 연결 실패와 로그아웃을 구분하고, 아직 온라인 확인 전인 상태를 표시합니다.
- 러닝 전에 약100m 위치 공유를 설정하고 같은 계정의 선택을 기억합니다. 실제 기록 중에만 전송하며 일시정지·종료·계정 변경 시 중단합니다.
- 지도 기본 제공자를 MapLibre Native/OpenFreeMap 벡터 지도로 교체했습니다. 핀치·드래그·경로와 미니미 표시를 유지하고 오류 시 기존 지도와 재시도를 제공합니다. 무료 공용 지도 서비스의 가용성을 보장하지 않습니다.
- 장비의 도트 명암·가림과 의복의 밀착감을 개선하고 산타·곰·골든 세트를 선택할 수 있게 연결했습니다. 승인 원본과 아이템 ID·보유 정보는 보존했습니다. 수영복은 아직 미승인입니다.

이 문서는 후보 변경 사항입니다. 실행 검사·서명·실제 APK의 버전/해시/출처와 게시 여부는 별도 검증 기록에서 확인합니다. 호스트 미니미 출력은 Android 화면이나 사용자 시각 승인으로 표시하지 않습니다.
