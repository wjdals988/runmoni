# 런모니 0.14.0-dev

- 출발 전 날씨와 새로고침을 홈에서 확인할 수 있어요. 야외 집중 화면에서는 거리와 남은 인터벌 시간이 크게 보여요.
- 1km 결과와 지도를 오가고, 공유 이미지나 사진을 불러오지 못하면 해당 화면에서 다시 시도할 수 있어요.
- 지도에서 러너를 바로 숨길 수 있어요. 크루 탈퇴는 먼저 확인하고, 채팅은 전송 결과와 다시 시도할 방법을 알려줘요.
- 로그인·게스트 선택과 프로필 입력을 정리하고, 옷장 색상과 위젯 읽기 안내를 다듬었어요.

기존 배포 키로 서명한 Android 개발 프리뷰입니다. 휴대폰 런처·야외 GPS·음성·진동은 실기기 확인이 남아 있습니다.
