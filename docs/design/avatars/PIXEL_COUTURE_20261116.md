# 미니미 착용 도트 개편 · 2026-11-16

사용자 지적은 장비가 따로 놀고 모자가 배경처럼 보인다는 것이다. 승인 원화의 얼굴·체형·포즈를 바꾸지 않고, 실제 착용 접점과 앞뒤 가림을 고치는 것을 먼저 한다. 새 결과의 사용자 시각 승인은 별도다.

적용 스킬은 [Pixel Art With Code](https://github.com/paean-ai/deeptide/blob/b48688d56c3eb61d0c028de2fa73dd674be2f3e8/skills/pixel-art-code/SKILL.md), frontend-design이다. 명시 격자·제한된 재질 팔레트·실루엣 우선·최근접 축소·작은 크기 비평을 채택했다. 스킬의 일반게임 2~3프레임/전투효과/새UI 제안은 채택하지 않고 기존8프레임·앱구성을 유지한다. 외부 스킬 코드는 실행하지 않았고 유료 API/패키지 설치는 없다. [Aseprite](https://github.com/aseprite/aseprite)의 cel/레이어를 참고하며 실제 Aseprite 제작물로 부르지 않는다.

- 격자: 원본256×384, 남녀2행×8열을 그대로 쓴다. 원본 SHA256 f9035f29ced0c7ba513dfe24cb727410a7204dc482fc457e806c7a9b3cdbfa65.
- 팔레트 역할: Ink #10172C, 깊은 스포츠 원단 #263B49, 중간 원단 #3D5864, 접힘 빛 #64848A, 밝은 털/실 #FFF8E9. 실제 옷 색 선택은 기존 독립팔레트를 유지한다. 피부/머리/눈을 재착색하지 않으며 원래 풍부한 명암을 넓은5색띠로 양자화하지 않는다.
- 가림: 뒷 실루엣 → 승인 전신/의복 → 머리카락 일부를 가리는 명시 모자 앞단/접촉 그림자 → 귀·눈 장비. 모자를 투명 배경에만 그리던 제한은 버린다. 원본PNG는 보존하고 눈·얼굴·피부/신체경계를 보호한다.
- 형태: 러닝 캡·바이저의 챙과 패널, 산타 모자의 털 앞단, 곰/골든의 실제 머리 착용면을 구분한다. 같은 캐릭터를 다른 얼굴/새 신체로 교체하지 않는다.
- 장비: 원근에 맞는 앞/뒤 렌즈와 귀 연결, 팔 방향의 워치, 몸통 원근·전경팔 가림을 따르는 조끼/벨트를 쓴다. 무작위반짝이/노이즈/과한1px선을 피한다.
- 재질: 칼라·커프·패널 가장자리의 짧은 명암 군집, 소재별 대비를 만든다. 크루양말은 밝게, 니삭스는 그래파이트 니트로 나눠 넓은 흰 붕대 인상을 줄인다.

아이템58ID·13슬롯·9탭/무료·성별·지갑·저장값·부위점유 규칙은 유지한다. 기존 러닝캡/선바이저 ID를 실제 준비했을 때만 선택 가능하게 한다. 미승인 수영복은 이번에 추가하지 않는다.
