# Avatar 0.3.0 — reference quality restoration

2026-10-25. 사용자가 첨부한 러닝 스프라이트의 품질을 현재 기준으로 고정한다. 방향은 사용자 선택 **오른쪽으로 달리는 3/4 측면**이다. v0.2.1의 간이 코드 렌더러 동작 후보는 사용자가 품질 미달로 채택하지 않았으며 앱에는 적용하지 않았다.

## 입력과 결과

- `user-quality-reference.png`: 사용자가 직접 첨부한 원화. 임시 폴더 원본을 별도로 복사해 보존했다. 사용자 제공 자료의 제작 도구·라이선스를 새로 주장하지 않는다.
- `running-motion-art-source.png`: 위 이미지를 직접 참조해 built-in `image_gen`으로 편집/재구성한 원화 시안. 2048×768px, 남녀2행×8열, 셀256×384px. 짧은 짙은 머리/코랄 싱글렛·쇼츠·민트화, 브라운 포니테일/민트 티·타이츠·코랄화를 유지했다.
- `running-motion-review.gif`: 원본의8열을 기계적으로 잘라 남녀1쌍으로 함께 재생한다. 8프레임×90ms=720ms·무한반복·서로다른8개픽셀프레임·468,101bytes를 확인했다. 프레임 위치를 수작업 보정하거나 새 그림을 덧그리지 않았다. 원화 프레임의 자세·앵커 편차가 남아 있는 검토용 재생이다.
- PNG는 RGBA이며 alpha0..254다. 바깥 표본(0,0), (255,300), (128,395), (10,400)은 모두alpha0이다. 투명 픽셀의 RGB가 남아 일부 뷰어에서 어두운 그라데이션처럼 표시되더라도 이를 불투명 배경으로 오판하지 않는다.

## 품질 기준

얼굴·큰 눈과 하이라이트·머리의 여러 톤 픽셀 군집·피부 명암·의상 주름·러닝화 디테일을 참조 원화 수준으로 유지한다. 신체를 단순 도형으로 다시 그리거나 해상도 숫자만 높여 같은 품질이라고 설명하지 않는다. 팔은 몸의 옆에서 앞뒤로 교차하고 반대쪽 다리와 함께 움직이며, 먼 팔은 몸통 뒤에 일부 가린다. 특수 의상도 이 기본 캐릭터에 옷을 입힌 모습으로 제작한다.

## 현재 검증 범위와 한계

이 결과는 **원화·동작 시안**이다. 정확한 순환 동작, 고정 앵커, 의상/헤어/신발별 레이어, 실제 Android 교체·APK·기기 검증을 완료한 게임 자산이 아니다. 8열에 놓였다는 사실을 자연스러운 8프레임 달리기 검증으로 대체하지 않는다. 기존의 앱0.1.3-dev·UI38개 검사 결과는 이 원화에 적용되지 않는다.

GIF의 프레임 수·지연·파일 크기·원본/프레임SHA-256은 `preview-verification.json`, 재현 스크립트는 `scripts/avatar/export-quality-motion.cjs`에 남겼다. 번들sharp 실행은 다른 채팅이 AVD0/빌드종료를 확인하고 넘긴 구간에1.2초 동안 수행한 후 바로 반납했다.

앱의 기존 AvatarRasterizer·카탈로그·보유품·지갑·업데이트 피드는 변경하지 않았다. 다른 채팅이 Theme/UI·Google 계정 작업을 소유하고 있으며 빌드·AVD·Git 전송은 중복 실행하지 않는다. image_gen 원본은 기본 생성 폴더에도 보존하고, 프로젝트용 결과와 참조는 현재 폴더에 저장했다. 제작 지시는 `prompts.txt`에 기록한다.
