# 승인 기본 러닝복 색상 마스크 v1

2026-11-04 한국 시간. 기본 상의·하의·신발 천의 독립 색상 선택을 위한 소스 고정 마스크다. **새 색상 결과의 사용자 시각 승인은 대기 중**이며 새 형태 의상·수영복·58종 원화 완성이 아니다.

## 원본과 데이터 계약

원본은 `../v0.3.0/running-motion-art-source.png`, SHA256 `f9035f29ced0c7ba513dfe24cb727410a7204dc482fc457e806c7a9b3cdbfa65`다. 원본/앱 번들/검토 사본을 덮어쓰지 않았다.2048×768/남녀2행×8열/셀256×384를 유지한다.

- `annotations.json`: 셀별 의복 좌표와 독립 머리/피부색/윤곽/흰 장식 보호 주석. 정적 원본에 맞춘 영역·팔레트 조건이며 런타임 피부 인식이 아니다.
- `fabric-mask.png`: alpha255, R=상의1/하의2/신발 천3, G=명암0..255, B=0. Alpha0이면 원본 복사. 원본 alpha는0..254이며255 조건으로 선택하지 않는다.
- `protected-mask.png`: 명시한 보호 픽셀만 흰색. 의복 마스크의 단순 역상이 아니다. 피부 보호의 일부는 소스 HSV 조건이므로 모든 의미상 피부를 완전 분류했다고 주장하지 않는다.
- `manifest.json`: 소스·마스크·보호 마스크·주석 SHA와 버전·라벨 의미. 마스크 SHA `462433ce98a7a2f52c98823d851bed462418bbab18f4262c75f6113456e74bb5`. 앱 사본도 같은 바이트다.

`python3 scripts/avatar/build-approved-kit-masks.py`는 기존 원본을 읽어 라벨 데이터만 만든다. 캐릭터를 새로 그리거나 몸통/팔다리를 조립하지 않는다. 작성된 protectionRules를 실제로 읽고 재컴파일한 PNG가 같은 바이트임을 확인했다. 생성 모델 편집과 Aseprite 실행은 하지 않았다. [Aseprite의 레이어/프레임 파일 규격](https://github.com/aseprite/aseprite/blob/main/docs/ase-file-specs.md)은 개념 참고다.

## 구현과 검토

앱은 별도 `recolorRunningKit(top,bottom,shoes)` API와 명암 팔레트를 사용한다. 원본색0은 원본 프레임을 그대로 반환한다. 다른 색은 원본 배열을 복사하고 명시 마스크 안만 바꾼다. 검증 실패 시 원본으로 돌아가며 UI의 색상 조작을 비활성화한다. 색상·성별·프레임·마스크 버전별 컬러 캐시의 한도는8MiB다.

초기 검토에서 여자 frame2의23px, 남자 frame2/frame6의7px씩 작은 천 조각이 연결성분 크기 제한에 걸려 남은 것을 찾아 좌표별 포함 주석으로 보완했다. 독립 검토자는 blue/purple/gold16셀 host 접촉표에서 뚜렷한 피부 변색·얼굴/체형·팔/다리 실루엣 변형을 찾지 못했다. 이 결과는 사용자 시각 승인이나 실제 Android 실행을 뜻하지 않는다.

호스트216조합×16셀3456사례는 [검증 기록](../../../app-review/2026-11-04-kit-colors/host-palette-verification.json)에 있다. 마스크 밖·명시 보호 영역·alpha 변경0, 다른 영역 불변·원본 배열 불변을 검사했다. 전체 의미상 피부의 완전 분류 검사로 확대하지 않는다.

여자 셀 상단12px에 원래 있던 윗행 신발 누출은 마스크에서 보호한다. 실제 표시에서는 별도 `renderForDisplay`가 해당 여백만 투명하게 한다. 원본 파일과 `render`의 raw 프레임은 그대로이고, 얼굴/머리/몸의 픽셀은 이 표시 보정으로 바꾸지 않는다. 이 보정은 의복 마스크 밖 불변 검사와 별도 범위다.

최종 Android 실행·저장/화면 재실행·큰 글씨·실제 앱 사진·사용자 승인 상태는 [실행 기록](../../../app-review/2026-11-04-kit-colors/README.md)에 구분해 기록한다. 기본 Firebase 모드의 색상은 기기 저장이며 Google 연결만으로 다른 기기에 복원되지 않는다.
