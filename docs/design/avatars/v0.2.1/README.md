## 현재 단계

앱에 설치된 최종 APK의 수정이 아니라 `work/avatar-motion-v021/candidate/AvatarRasterizer.java` 후보에서 직접 내보낸 동작 비교다. 기존 앱의0.1.3-dev/code4·UI38개 검증을 이번 후보의 검증 결과로 사용하지 않는다. 이 단계에서 앱 소스·카탈로그·지갑·보유품·업데이트 피드는 변경하지 않았다.

- `motion-before-after.gif`: 왼쪽 기존 / 오른쪽 수정안. 기본 러너·산타·곰인형, 각 쇼트/포니테일 동일 얼굴·의상 조건. 8프레임×90ms=720ms, 무한 반복, 서로 다른8프레임. Android 캡처가 아닌 공통 렌더러의 데스크톱 출력이다.
- `motion-frame-comparison.png`: 위 기존 / 아래 수정안, 기본 러너의8프레임을 나열했다.
- 수정안은 running 전용 어깨 간격23→8px, 앞팔 손목 가로 이동폭32→16px, 팔꿈치87.5~92.2도다. 원거리 팔→몸통→가까운 팔 순서로 가리고, 같은 쪽 팔과 다리가 반대로 전진한다.
- 몸통·허리·조끼·벨트는 함께 가로0.78 투영해 옆으로 향하는 폭을 만들고, 머리·옷·팔다리를 최종 래스터에서 함께 약4도 기울였다. 얼굴·목을 독립적으로 잘라 이동하지 않는다.
- 발의 가로 보폭은 기존의0.8배, 코스튬 발은 일반 러닝화 실루엣과 공유한다. 프레임 수·주기만 늘려 자연스럽다고 주장하지 않는다.

실제 재생의 자연스러움은 사용자와 비교 GIF로 검토 중이다. 좌표·프레임 메타데이터·읽기 검토만으로 미적 품질 승인이나 앱 반영 완료를 대신하지 않는다. 후보의 목 연결·화면 경계 회귀 검증 및 앱 통합은 이후 단계로 남긴다.

Aseprite의 레이어·프레임 개념을 참고한 기존 코드 기반 픽셀 리그를 수정했다. 실제 Aseprite 편집 파일이나 생성형 이미지 제작물이라고 표시하지 않는다. 새 패키지 설치·네트워크·Gradle/AVD 실행 없이 캐시 JDK와 번들 이미지 인코더로6.3초 동안 순차 내보냈다. 다른 채팅의 AVD 진단과 실행 구간을 명시적으로 조율했다.
