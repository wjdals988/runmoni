# Runmoni RPG avatar preview 0.1.0 — 2026-10-25

## 사용자 확정 방향

- 이전 두 번째 시안의 큰 머리·약 3등신 RPG 사람 캐릭터 비율을 유지한다.
- 남자/여자 기본 시안을 제공하되 헤어와 의상 선택을 성별로 제한하지 않는다.
- 러닝복·러닝화·스포츠 워치·헤드밴드·바이저·수분 보급 조끼·러닝 벨트를 사용한다.
- 사진, 갑옷, 무기, 과장된 판타지 장비는 사용하지 않는다.

## 이번 결과와 실제 범위

- `runner-presets-v1.png`: 남녀 각 3개, 총 6개 정적 콘셉트. 쇼트·가르마·포니테일·단발 헤어 예시, 반팔·싱글렛·긴팔과 쇼츠·타이츠를 제안한다. 모든 아이콘이 분리된 원화 파일이라는 의미는 아니다.
- `run-atlas-source.png`: built-in image_gen으로 생성한 원본 투명 PNG. 실제 크기 1774×887px, 4열×2행, 남녀 각 4프레임. 원본은 수정하지 않고 보존했다. 정확한 64×64 제작 자산이 아니다.
- `running-pair-preview.gif`: 원본 프레임을 순서대로 잘라 나란히 배치한 실제 GIF. 각 프레임 120ms, 4프레임, 480ms 반복. 사용자가 신고한 PC 지연을 고려해 로컬 이미지 인코딩과 검증은 순차 실행했다.
- `wardrobe-preview.html`: 오프라인 선택형 미리보기. 헤어 2종 × 러닝 세트 2종 = 4조합을 남녀 양쪽에 동일하게 제공한다. 헤어에는 헤드밴드/바이저가 포함되고, 세트에는 상의·하의·신발·워치가 포함된다. 액세서리와 신발의 독립 선택은 아직 없다.
- `preview.fragment.html`: base64 데이터 삽입 전 편집용 원본. 실행 결과는 `wardrobe-preview.html`이다.
- `run-atlas-preview.webp`: 미리보기용 WebP 형식 내보내기. 원본 PNG 보존, 알파 채널 유지. 시안 파일 생성에 Aseprite 설치·컴파일은 사용하지 않았다.

## 제한과 다음 제작 단계

생성형 프레임마다 신체·팔 위치가 조금씩 달라 상의와 하의를 수평 경계로 나누면 허리와 손목에 단절이 발생했다. 이 방식은 폐기하고, 세트 전체를 유지하면서 목 위 헤어를 교체하는 미리보기로 정리했다. 이는 Android 앱의 완성된 옷장 기능이 아니다. 기존 MiniMi·지갑·꾸미기 소유 정보·접근성 코드는 이번 작업에서 변경하지 않았다.

실제 앱 제작은 공통 프레임 좌표와 부위별 마스크를 먼저 확정한 후 진행한다. 목표 슬롯은 `hair`, `top`, `bottom`, `shoes`, `headwear`, `eyewear`, `wrist`, `waist`, `hydration`이며 성별 잠금은 두지 않는다. 부위별 원화와 포니테일 앞/뒤 레이어, 팔의 앞/뒤 순서, 헤드웨어 충돌, 장비 가독성은 별도 검증해야 한다. 4프레임은 동작 방향 확인용이며 최종 8프레임 원화를 대신하지 않는다.

앱 적용·APK 빌드·실기기 검증·동기화·Aseprite 원본 생성·원격 배포는 수행하지 않았다. 네트워크 서버·외부 터널·방화벽 예외·에뮬레이터·패키지 설치도 사용하지 않았다.

## 확인 결과

`scripts/check-avatar-preview.cjs`를 로컬 headless Edge에서 순차 실행:

- GIF 4프레임, 프레임당 120ms, 무한 반복 메타데이터 확인.
- 남녀 각각 4조합, 총 8회 변경: 각 캐릭터의 렌더링 결과 4개가 서로 다름을 확인.
- 달리기 프레임 진행·일시정지 동작 확인, 브라우저 JavaScript 오류 0개.
- 320px 화면 가로 넘침 0개. 기본/교체/모바일 화면을 `work/avatar-preview/`에 저장하고 시각 검토.
- 최초 8조합 시도의 허리 단절을 시각 검토로 발견하여, 단절 없는 4조합 세트 미리보기로 변경. 테스트 통과를 모든 제작 레이어의 정합성 보증으로 표현하지 않는다.

## 재생성

추가 패키지 설치 없이 `RUNMONI_NODE_MODULES`에 번들 Node 패키지 경로를 지정한 뒤 다음 스크립트를 순서대로 실행한다.

```powershell
node scripts/build-avatar-preview.cjs
node scripts/check-avatar-preview.cjs
```

첫 스크립트는 원본 이미지를 새로 생성하지 않고 저장된 PNG에서 WebP·GIF·미리보기만 내보낸다. 두 번째는 로컬 브라우저 검증이다. 외부 HTTP(S) 요청은 차단한다.

## 최종 제작 프롬프트

이미지 생성은 built-in image_gen 모드다. 앞선 승인 시안 PNG를 스타일 참조로 사용했다. 원본 생성 프롬프트는 `prompts.txt`에 보관한다. GIF는 새 그림을 그리지 않고 생성된 프레임을 조립해 내보냈다.
