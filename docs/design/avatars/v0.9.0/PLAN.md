레이어 순서는 의복/양말 → Aseprite 의복·헤어·볼 장식 → 머리장비 → 조끼 → 벨트 → 워치 → 이어폰 → 선글라스다. 각 장비 부위에서 기존/새 선택을 함께 처리해 세대가 섞여도 물리적 가림 순서를 유지한다. 독립된 손 보호와 원본 alpha를 지키며, 같은 부위 새 장비는 기존 장비와 동시에 그리지 않는다. 의복 색은 별도 Aseprite tint-label 셀의 역할/명암으로만 바꾼다. 피부/눈/머리/윤곽/밑창에 전역 필터를 적용하지 않는다. 프로젝트는 잠긴 원본·현재 형태와 별도 새 그림 레이어, 숨긴 역할 명암 레이어로 구성한다. PNG는 선택한 셀만 읽는 제한된 LRU를 사용하며 미리 전체624셀을 생성하지 않는다.

검토는 원본/기존/새 출력, 남녀8포즈,80/112/144px, 여러 동시 장비 및 색 선택을 구분한다. 수량·hash·보호 검사만으로 상업 품질/사용자 승인을 주장하지 않는다.
