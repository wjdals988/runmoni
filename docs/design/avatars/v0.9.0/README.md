# Aseprite 아틀리에 확장 · 0.9 후보

[아이템 계획](PLAN.md)과 [정확한39개 ID/이름](item-plan.json)은 기존61개 ID 뒤 각13슬롯3개를 추가한다. 헤어는 커트를 바꾸지 않는 결 재질이며 얼굴3종은 표정 대신 볼 한정 장식이다. 여성 하의는 원래 타이츠/실제 타이츠 덮개를 유지한다. 새 세트3종은 같은 캐릭터의 기술 러닝복이며 머리·체형을 바꾸지 않는다. 새100개 전체의 원화 준비가 완료됐다는 뜻은 아니다. 기존 미준비 아이템은 그대로 구분한다.

실제 도구 실행·PNG/프로젝트 원본·hash·작은 크기 및 Android 검토는 Root의 별도 증거 자료를 따른다. 이 문서는 제작 계약이며 사용자 시각 승인·상업 품질 인증을 뜻하지 않는다. 실제 headless Aseprite 버전은 기존 환경의1.3.18.6-dev이며, GUI 손그림이나 공식 무수정 빌드를 사용했다고 주장하지 않는다. Aseprite 프로그램·제3자 소스·빌드 바이너리는 배포하지 않는다.

`ExportAtelierReferences.java`는 승인 원본/부위별 고정 마스크와 기존 순수 렌더에서 참조를 내보낸다. `author-expansion.lua`가 Aseprite 안에서39개×16포즈의 새 그림과 의복12종×16포즈의 색상 역할·명암 레이어를 작성한다. 잠긴 원본 참조·기존 형태 참조·실제 기본층, 새 그림, 숨긴 색상 역할층은 분리된다. `.aseprite` 보관/압축 형식과 최종 수량·hash는 실행 후 기록을 따른다.

원본 `f9035f29ced0c7ba513dfe24cb727410a7204dc482fc457e806c7a9b3cdbfa65`는 수정하지 않는다. 새 도형은 기존 의복/장비 표면과 별도 머리/볼 영역으로 한정한다. 피부·눈·입·귀·원래 윤곽선·밑창을 전역 착색하지 않는다. 여성 헤어6의 포니테일 빛은 별도의 명시 다각형 안에서만 그린다. 같은 부위 장비는 중복하지 않고, 옛/새 아이템을 섞어도 모자→조끼→벨트→워치→이어폰→선글라스 순서를 따른다. 의복은 각 셀의 별도 역할/명암 PNG로 색을 바꾸고 고정 반사/스티치 색을 구분한다.

런타임은 선택한 셀만 hash 확인 후 읽는8MB LRU를 쓰며 전체624개 PNG를 한꺼번에 디코딩하지 않는다. 새 의복의 독립된 손 보호층은 의복 레이블보다 우선한다. 기본 원화와 기존80개 Aseprite 소재 셀·사용자 저장 ID·지갑/포인트/보유·성별·9탭/13슬롯을 유지한다.

1차 헤어는 작은 크기에서 구별이 약하고 원래 부드러운 명암 위에 점무늬 노이즈를 더해 Root/독립 검토에서 거절됐다. 2차는 점무늬 전체를 제거하고 앞머리 흐름/측두부와 앞머리 두 면/뒷머리 또는 포니테일 끝의 연결된 큰 광택 덩어리로 재설계했다. 조끼5는 실제 사각 수납부에 맞게 ‘듀얼 포켓 조끼’로 명칭을 교정했다. 실패한 시안을 최종 승인으로 바꾸지 않는다. `review-contacts.lua`의 작은 크기 사진은 호스트 Aseprite 합성 검토이며 Android MainActivity 화면이 아니다.

최종 V4는 카테고리별13개 순차 실행의 종료0 영수증과39개 .aseprite 원본·624그림셀·192의복 역할셀을 완성했다. 모든624셀의 실제 변경은20픽셀 초과다. V2에서 발견한 남자 헤어6의3픽셀 문제는 후두부/정수리 명암으로 보완했으며 여자 헤어6과 다른808PNG는 동일하다. 상세 제작·실패·소규모 시각 검토는 [앱 검토](../../../app-review/2026-11-17-expressive-refresh/ASEPRITE_REVIEW.md)를 따른다.
