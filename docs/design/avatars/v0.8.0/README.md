# Aseprite 의복 소재 셀 · 0.8 후보

승인 원본 얼굴·체형·8프레임을 보존하며 실제 Aseprite Lua로 별도 디테일 레이어를 제작·저장했다. 실제 실행 버전은1.3.18.6-dev다. 공식v1.3.18.6 소스에 로컬 headless 연결부를 조정한 배치판으로 GUI·손그림 제작을 주장하지 않는다. 프로그램/공식 소스/빌드 바이너리는 앱과 저장소에 배포하지 않는다.

프로젝트5개는 각256×384/16프레임(male1~8, female9~16), 원화 기준·현재 의복 참조·새 디테일의3레이어다. 두 참조 레이어는 잠갔다. 실제 앱에는 프로젝트가 아니라 원래 alpha를 유지하는 별도80PNG셀을 넣으며 의복 마스크·얼굴/손 보호를 이중 적용한다. 새 메시 저지·리브 양말·패널 신발3종은 별도 코드 제작층이며 Aseprite 제작물로 혼칭하지 않는다.

원본f9035f29ced0c7ba513dfe24cb727410a7204dc482fc457e806c7a9b3cdbfa65는 수정하지 않았다. 원본의 표정/비율을 다시 생성하거나 미승인 수영복을 넣지 않았다. 곰/골든은 후드 운동복 소재의 개선이고 전신 털 인형 원화가 아니다. 작은 R자수는80/112px에서 작은 청록 표식으로 보인다. 숫자 검사/호스트 출력·Root 검토는 Android 실행·사용자 승인과 별개다.
