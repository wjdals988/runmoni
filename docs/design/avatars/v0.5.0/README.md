## 원본·조립 실패와 구분

승인 기준 원본은 `../v0.3.0/running-motion-art-source.png`이며 SHA256은 `f9035f29ced0c7ba513dfe24cb727410a7204dc482fc457e806c7a9b3cdbfa65`다. 수정하거나 교체하지 않았다. 0.4의 새로운 PNG 신체 부품과 관절 회전 조립 결과는 사용자가 원본과 이질적이라고 거절했다. 기존 0.4 README의 통합/수치 검증 기록을 시각적 승인으로 해석하면 안 된다. 이번 시안은 0.4 리깅을 사용하지 않는다.

## 확인 결과와 미확인 범위

`scripts/avatar/inspect-swimwear-preview.cjs`가 PNG를 읽기만 하여 크기·파일 해시·alpha·바깥 여백을 검사했다. 결과는 `preview-inspection.json`이다. 두 이미지의 alpha는 0..255, alpha≥16 경계는 각각 `[60,59,1372,1044]`, `[59,59,1372,1046]`으로 캔버스 바깥에 잘리지 않는다. 배경의 완전 투명 픽셀도 각각 913985/932621개 있다.

눈으로 확인한 큰 얼굴/헤어 실루엣·체형·포즈는 기준을 따르는 시안이지만 **원본과 얼굴 픽셀·비율이 수치적으로 완전히 동일하다고 검증된 결과는 아니다**. 색상 편집도 생성 모델이 전체 이미지를 다시 출력하므로 얼굴/피부/투명도에 변화가 남았다. 두 색상안의 고정 얼굴 사각형에서 공통 불투명 픽셀 중 RGB 차이가 3을 넘는 수는 남자 46157/66004, 여자 37352/61788이다. 이 검사는 같은 이미지 위치의 픽셀 비교이며 인물 유사도나 미적 점수가 아니다. 색 이외를 정확하게 보존하는 앱 기능으로 대체해 설명하면 안 된다.

후속 앱 구현은 의복의 명시적인 프레임별 색상 마스크/명암 팔레트를 사용하여 피부·얼굴·머리·윤곽·밑창을 색 변경에서 제외해야 한다. 비키니 상·하의를 독립 선택할 수 있게 준비하되, 현재 원화에 해당 마스크나 실제 저장/선택 UI가 구현된 것은 아니다.

8프레임 달리기/여자 양팔 수정, 58종 착장 전체의 원본 품질 복원, 런타임 색상 변경, Android 캡처, APK 빌드·기기 검증·공개 배포는 이번 시안 제작에 포함되지 않았다. 현재 앱의 0.4 렌더러는 그대로이며 **앱 복구 완료가 아니다**.
