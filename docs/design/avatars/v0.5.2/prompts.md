# 생성 지시와 후처리 범위

도구: built-in image_gen. 참조 1은 v0.3 승인 시트, 참조 2는 v0.5 민트/코랄 정지 시안이다. `transparent_background=true`. 이미지 생성 1회, 다른 설치/빌드/AVD와 겹치지 않게 실행했다. 원본 생성 PNG SHA256은 `bfaa139f349ae8daaacc308c6bb67aeed2dfe738a42ce0755474ac9305f3b074`다.

요청의 핵심: 첫 참조를 유일한 얼굴·체형 기준으로 사용, 두 번째는 수영복 형태만 참고. 2048×768의 남녀2행×8열, 셀256×384. 남자 상의 없음/청록 보드숏, 여자 코랄 비키니, 원래 신발·양말 유지. 오른쪽 3/4 달리기와 반대 팔·다리 위상, 특히 여자 화면 왼쪽 팔의 앞뒤 움직임을 요구. 얼굴의 눈/하이라이트/입/귀·짧은 신체 비율·픽셀 군집·네이비 윤곽 보존, 새 신체 부품 조립 금지, 배경/그리드/라벨 제외.

이 요청을 모델이 모두 만족했다는 뜻은 아니다. 생성 결과의 비의복 픽셀 차이를 확인해 그대로 사용하지 않았고, `GarmentPalette.protectIdentity`가 명시적 마스크에서 승인 원본 픽셀을 다시 사용한다. 의복 색 변경 역시 모델 재생성이 아닌 프레임별 마스크/팔레트를 사용한다. 표시 단계는 이전 행의 발이 섞이는 상단12px 여백을 제외하며 원본 파일은 보존한다. 동작·체형의 시각적 승인과 전체58종 제작은 남아 있다.
