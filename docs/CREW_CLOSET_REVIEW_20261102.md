# 크루 계층·옷장 UI/UX 검토 — 2026-11-02

사용자 요구는 크루를 최상위로 두고 파티를 하위의 유동 집단으로 만드는 것, 전체 텍스트 정렬/화면 단계/옷장 카테고리 개선, 테스트 아이템 무료화와 성별 전환이다.0.3.0-dev/code12 개발 변경이며 공개0.2.1의 배포 검증과 구분한다.

## 서브에이전트 토론과 반박 반영

UI/UX 검토(`ux_critical_review`), Firebase 권한/수명주기(`community_lifecycle`), 원화·성별/무료 정책(`avatar_gender_free`)을 나누고 서로의 변경을 독립 검토했다. 아래는 실제 제기한 문제와 반영 결과다.
