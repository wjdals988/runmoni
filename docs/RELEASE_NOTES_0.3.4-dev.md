# Runmoni 0.3.4-dev — 옷장·화면 구획 개선

실제 휴대폰 검증 전 개발 프리뷰입니다. 새 의복·장비의 사용자 시각 승인은 아직 받지 않았습니다.

- 옷장을 메인 하단 탭과 분리한 전체 화면으로 바꿨습니다. 미니미·성별·카테고리를 위에 고정하고 품목을 단순한 목록으로 정리했습니다.
- 원화·수영복 시안 비교를 제품 옷장에서 제거했습니다. 마지막 품목과 색상 조작은 시스템 하단 영역 위에서 스크롤해 선택합니다.
- 승인된 전신 원본 위에 반팔·긴팔·지퍼 상의·타이츠·신발 팔레트와 헤드밴드·이어폰·선글라스·워치·벨트·수분 조끼를 연결했습니다. 옷장 선택을 현재 미니미·홈·지도 표시 경로에 반영합니다.
- 기존58개 ID 중 기본13개와 비기본23개, 합계36개가 실제 표시됩니다. 원화가 없는22개는 새 선택을 제한하고 기존 저장 ID·보유권·포인트는 보존합니다. 모든 아이템0P와 성별 전환은 유지합니다.
- 품목을 바꾸면 해당 부위만 그 품목의 기본색으로 착용합니다. 같은 품목을 다시 누르면 사용자가 고른 색을 유지하고 다른 부위의 색은 보존합니다. 색상0은 선택한 품목의 기본색입니다. 기본 Firebase 경로의 옷장·색상은 기기 저장 범위입니다.
- 행동/입력8dp·표면12dp 모서리와 제목·구분선·간격으로 홈·기록·계정·파티 화면의 구역을 분명하게 정리했습니다. 업데이트 레드닷·확인 후 다운로드와 기존 기록 복구 흐름은 유지합니다.

- 작은 창에서도 새 메시지로 이동할 수 있도록 채팅 기록 위에 조작을 표시했습니다. 키보드 입력창의 높이는 줄이지 않습니다.

원본 얼굴·체형·팔다리를 재생성하지 않았습니다. 안경·밴드 등은 해당 부위를 의도적으로 가리며 얼굴/몸 자체를 교체하지 않습니다. 수영복·새 헤어/표정·모든58종 원화 완성은 별도 작업입니다. 실제 휴대폰·Google·운영 두 기기 쓰기·야외 GPS는 미검증입니다. 기존 보관 서명키를 사용하며 새 Firebase Rules 변경은 없습니다.
