# 러닝 관리·기록 지도·화면 개선 — 2026-11-10 한국 시간

## 문제와 변경

- 알림 제어는0.3.7부터 존재한다. 이번에는 러닝 화면에 안내·알림 설정 진입을 유지하고 러닝 옵션에 홈 화면 위젯 추가를 연결한다. 상태 표시줄의 작은 아이콘은 러닝 알림의 진입점이며, 실제 제어는 알림 패널 또는 위젯이다.
- 위젯은 Android RemoteViews/AppWidgetProvider를 사용한다. 진행 중 거리·시간·속도의 마지막 갱신값과 기준 시각을 표시하고5초 이내 중복 갱신을 줄인다. 일시정지·재개는 해당 runId와 살아 있는 서비스 확인을 모두 거친다. 종료는 앱의 기존 확인 화면으로 이동한다. 위젯/재부팅/오래된 버튼으로 GPS·새 러닝·서비스를 자동 시작하지 않는다.
- 프로세스가 사라진 뒤 런처가 예전 RemoteViews를 보관할 수 있다. 시간이 임의로 증가하는 Chronometer를 쓰지 않고 마지막 기준 시각을 남긴다. 다음 갱신은 ‘마지막 러닝 정보’로 전환한다. 작은 크기·큰 글씨는 앱 열기로 전환하며 실제 기록의 근원은 기존 Room/러닝 서비스다.
- 저장 기록은 전체 페이지로 열고 글로벌 하단 내비게이션을 제거한다. 뒤로 가면 원래 탭 상태로 돌아오며 GPX/계정 요약 백업/삭제는 스크롤로 접근한다. 삭제 실패는 상세에 남기고 실제 목록 제거 뒤 닫는다. 백업·삭제 확인은 대상 기록/계정이 바뀌면 철회한다.
- 지도 키가 없던 경로선 전용 화면에 실제 OpenStreetMap 배경을 추가한다. 기존 Naver 설정이 있을 때는 SDK 경로를 유지한다. 기록 지도는 전체 경로를 맞추고 중단/불량 지점을 연결하지 않는다. 지도는 한 손가락 페이지 스크롤을 양보하고 두 손가락 이동·확대와48dp 버튼을 제공한다.
- 홈 민트 영역·짙은 녹색 CTA·프로필 실제 기록 요약·작은 목록 아이콘 색·연결 오류의 코럴 색을 사용한다. 가짜 그래프/코스/수치나 모든 섹션의 장식 카드는 추가하지 않는다. 시스템 글꼴·기존 미니미·8dp 버튼/12dp 표면과 기존 데이터는 유지한다.

## 지도 제공자·캐시·개인정보

- 표준 서버 `https://tile.openstreetmap.org/{z}/{x}/{y}.png`, User-Agent `Runmoni/<실제 앱 버전> (Android; https://github.com/wjdals988/runmoni)`. © OpenStreetMap contributors 표기와 [저작권/ODbL 안내](https://www.openstreetmap.org/copyright)를 지도 아래 계속 표시한다. 지도 데이터 라이선스와 표준 서버 사용 정책은 별개다.
- 한 번에 HTTP1개, 현재 viewport만 요청한다. 위치를 알 수 없는 기록은 임의 지도를 만들지 않는다. 원본 GPS 목록/계정/토큰은 보내지 않지만 **요청한 타일 좌표와 접속 IP/앱 User-Agent로 조회 영역이 제공자에게 드러난다**. 기록/GPX 자체는 기존 기기 보관이며 Google 백업은 별도 명시적 요약 동작이다.
- Cache-Control/Expires/ETag/Last-Modified를 따르고 조건부 재검증한다. 유효 캐시 헤더가 없을 때만7일 기본값을 사용한다. no-store/no-cache/must-revalidate를 존중하고429/503은 재시도 제한을 따른다. 메모리8MiB·기기 캐시 디스크24MiB/64타일 상한이며 앱 데이터가 아닌 제거 가능한 cache다.
- 기본 요청에 no-cache를 넣지 않는다. 타일 사전 로드·다중 확대 수준 수집·오프라인 다운로드·원본 타일 번들/배포를 하지 않는다. 지도 연결 실패는 상태/재시도를 표시하고 저장 경로선은 유지한다. 표준 서버는 무상 best-effort이고 SLA가 없으므로 규모 확대 전 적합한 제공자/자가 호스팅과 주소 교체를 검토한다. 이번에 유료 서비스나 공개 터널은 만들지 않았다.
- 자동 UI 검사는 unavailable test tile source를 주입하여 실제 OSM에 요청하지 않는다. 합성 배경·연결 실패 fixture를 실제 지리 지도나 온라인 성공으로 표시하지 않는다. 실제 지도 조회/출력은 별도 실행 근거에 기록한다.

## 검증 상태

제품 입력 source6의 로컬 빌드에서 JVM 141개(실패·오류·skip 0), lint 오류 0/경고 43을 확인했다. Android는 source4의 핵심 16개 성공 보존과 source6의 새 3개 통과를 구분한다. 단일 바이너리의 새 19회가 아니다. 변경 범위와 실패·수정·복원은 [실행 기록](app-review/2026-11-10-running-experience/README.md)에 남긴다.

별도 debug7의 세션 전용 TLS overlay에서 앱의 네이티브 HTTPS 타일 수신과 실제 지리 배경을 관측했다. 제품 main/배포 보안 XML·서명키는 바꾸지 않았다. 이 관측은 공개 서명 APK나 일반 휴대폰의 네트워크 검증과 다르다. live1~6 전체 시나리오 실패를 보존한다. live7의 기록 중심 제한 동선과 복원을 통과했으며 알림 제어는 live6의 실제 ACK만 별도 보존한다.

휴대폰·야외 GPS·Doze/OEM·API31 이상·Google 로그인·운영 쓰기·사용자 시각 승인은 별도다. 기존 성공 결과를 새 변경의 실행 성공에 합산하지 않는다.
