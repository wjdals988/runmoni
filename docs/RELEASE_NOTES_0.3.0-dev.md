# 런모니0.3.0-dev — 크루·파티와 미니미 옷장

**실기기 검증 전 개발 프리뷰**입니다. 크루를 최상위로 두고 소속 파티를 만들고 참가·삭제하도록 화면과 권한을 정리했습니다.

- 크루 목록 → 크루 상세 → 소속 파티 상세로 이동합니다. 가입 전에도 공개 파티 일정을 보고, 참가할 때 크루 가입을 명시합니다. 파티 삭제는 주최자/크루장이 확인 후 실행하며 목록·신규 참가·채팅 접근을 닫습니다. 기존 대화 문서와 개인 러닝을 일괄 파괴하지 않습니다.
- 반복 버튼 상자 대신 가로 탭을 사용하고, 제목/본문/목록의 정렬과 화면 단계를 정리했습니다. 큰 글씨에서는 옷장 아이템을1열로 표시합니다.
- 승인 원본의 남자/여자 기본형을 전환하고 저장할 수 있습니다. 원본 얼굴/체형/8프레임을 그대로 사용합니다.
- 테스트 기간 모든 기존 아이템을0P로 획득·선택 저장합니다. 기존 포인트/보유권은 유지합니다. **미준비 의상은 선택만 저장하고 승인 기본형을 표시합니다.** 여자 기본형 연결을 전체 의복58종/수영복 원화 완성으로 표시하지 않습니다.
- 빠른 선택 때 이전 요청이 다른 의상/성별을 덮어쓰지 않도록 저장을 정리했습니다.

**파티 삭제에는 최신 Firebase 규칙 게시가 필요합니다.** 이 버전은 서버 규칙을 자동 게시하지 않습니다. 소유자는 [현재 전체 규칙](https://github.com/wjdals988/runmoni/blob/main/firebase/firestore.rules)을 기존 Firebase 프로젝트의 Rules에 게시해야 합니다. Android 설정 파일/Secret/서명 지문을 다시 등록하거나 유료 서버를 만들 필요는 없습니다. [안내](https://github.com/wjdals988/runmoni/blob/main/docs/FIREBASE_COMMUNITY.md).

기존0.1.6/0.2.0/0.2.1과 같은 보관 키를 사용합니다. 실제 휴대폰 업데이트·Google 로그인·운영 방 생성/삭제·두 기기 채팅·야외 GPS는 별도 확인이 필요합니다. 클라우드 demo Firebase/Android 검사와 운영 사용자 성공은 구분합니다. 지도·음성/음악 방송은 별도 연결/검증 범위입니다.
