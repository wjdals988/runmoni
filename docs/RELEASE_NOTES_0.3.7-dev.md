# 런모니0.3.7-dev — 화면 개선과 백그라운드 러닝

홈·탐색·러닝·크루/파티·채팅·프로필·옷장·설정과 앱 정보에 같은 화면 기준을 적용했습니다. 제목·목록·주요 행동의 순서를 정리하고 작은 화면·큰 글씨·키보드에서 조작할 공간을 보강했습니다. 기존 녹색과 승인 미니미를 유지합니다.

앱을 내려놓거나 화면을 꺼도 위치 foreground service에서 러닝 기록을 이어갑니다. 러닝 화면에 현재 속도를 추가했고, 러닝 알림에서는 거리·시간·속도·페이스와 일시정지·재개를 제공합니다. 종료는 앱의 확인창에서 저장한 뒤 마칩니다.

알림 권한이 꺼져 있으면 설정으로 이동할 수 있으며, 알림 거절로 기기의 러닝 기록을 막지 않습니다. 오래된 알림이 다른 러닝을 바꾸지 않도록 보호했습니다. 기존 기록·포인트·꾸미기·Google/게스트 선택과 같은 서명키를 유지합니다.

실제 휴대폰 검증 전 개발 프리뷰입니다. 시스템 강제 종료나 Task Manager 중지 뒤에는 저장한 지점에서 복구하며 공백을 달린 기록으로 만들지 않습니다. 클라우드 AOSP/API29와 합성 GPS 검증은 실제 야외 GPS·제조사 절전·Doze·Android12이상·Google 인증·운영 쓰기 검증을 대신하지 않습니다.
