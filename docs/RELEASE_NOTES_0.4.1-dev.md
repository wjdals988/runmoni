# Runmoni0.4.1-dev — 위젯 가독성·날씨 배치·새 꾸미기

위젯은 크기와 글자 설정에 맞춰 거리·시간·조작을 배치합니다. 최소형도 실측해 한글 잘림과 긴 숫자 넘침을 막고, 공간이 부족하면 앱 열기를 남깁니다. 사용자가 고른 글자 크기를 줄이지 않습니다. 실행 중 현재 러닝에만 제어가 연결됩니다.

홈 미니미 옆에 기온·바람·강수·옷차림을 모았습니다. 좁거나 글자가 크면 러닝 시작 버튼 뒤로 펼칩니다. MET Norway 예보·제공자/시각·이전 정보/실패 구분은 유지합니다.

크루 양말·니삭스를 남녀 원본 프레임에 추가하고 남자 그린·코랄 쇼츠를 연결했습니다. 여자 양말은 기존 타이츠 위에 입는 형태이며, 여자 쇼츠나 가려진 피부를 새로 만들지 않았습니다. 원본 얼굴·체형·8프레임과 기존58개 ID/보유권·포인트·무료 정책을 유지합니다. 새 의복의 사용자 시각 승인은 별도입니다.

실제 휴대폰 검증 전 개발 프리뷰입니다. 같은 보관 키를 사용하며 휴대폰 런처·글자 설정·장시간 러닝/절전·Google 로그인·Android12이상·운영 공유 검증은 별도입니다. Firebase 규칙·인증 설정·앱 의존성은 이번 버전에서 바꾸지 않았습니다.
