# 런모니 0.10.0-dev

미니미 의상과 장비를 추가하고 달리기 화면과 앱 사용 흐름을 다듬은 Android 개발 프리뷰입니다.

1. **옷장**에서 레이스·야간 도심·트레일 의상과 장비 15종을 골라 입을 수 있어요. 선바이저, 방풍 셸, 러그 러닝화, 플라스크 조끼, 젤 벨트, 실드를 기존 의상과 조합해 보세요. 상의·하의·신발의 색은 따로 바꿀 수 있어요.
2. **홈과 러닝 준비**에서 날씨와 위치 상태를 확인하고 출발해요. 위치 공유에 프로필 연결이 필요할 때는 연결 화면을 바로 열 수 있어요. 기록이 없는 주에는 짧은 안내가 나와요.
3. **러닝과 기록**에서 트랙을 닮은 패널로 거리·시간·페이스를 읽기 쉽게 배치했어요. 기록 상세에서는 공유를 바로 열 수 있어요.
4. **탐색·크루**에서 지도를 옮긴 뒤 내 위치로 돌아올 수 있어요. 주변 러너는 러너 보기를 켰을 때 불러오고, 크루에서는 예정된 파티를 먼저 표시해요.
5. **공유 편집**에서 비율을 바꿔도 조작 위치가 유지돼요. 미리보기 위에서 선택한 비율과 스타일을 확인할 수 있어요.

새 도트는 승인 미니미의 남녀 각 8포즈에 피팅했습니다. [옷장 크기 착용 비교와 Aseprite 편집 원본](https://github.com/wjdals988/runmoni/tree/main/docs/design/avatars/atelier-v3)
