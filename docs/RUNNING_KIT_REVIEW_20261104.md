# 0.3.3-dev 기본 러닝복 색상 검토

2026-11-04 한국 시간. F03의 첫 묶음은 승인 원본의 기본 상의·하의·신발 천 색상을 독립 선택/저장하는 기능이다. 새 의상 형태·수영복·58종 원화 완성이 아니며 사용자 시각 승인은 대기 중이다.

## 원본과 렌더

승인 v0.3 원본·번들·검토 사본의 SHA256 f9035f29ced0c7ba513dfe24cb727410a7204dc482fc457e806c7a9b3cdbfa65를 보존했다. 얼굴·체형·팔다리를 새로 생성하거나 v0.4 관절 부품을 재사용하지 않는다. 명시적 프레임 라벨·명암 마스크와 팔레트로 기존 천의 색만 변경한다. [마스크 계약/소스](design/avatars/running-kit-v1/README.md).

마스크 작성은 소스 고정 좌표·색 조건과 독립 보호 주석을 사용한다. 앱 런타임에는 피부/색 추정을 하지 않는다. 보호 주석의 HSV 피부 조건을 모든 의미상 피부의 완전 분류로 해석하지 않는다. 원본색0은 raw 원본 프레임을 그대로 반환하고, 다른 색은 마스크 밖·명시 보호 영역·alpha를 유지한다. Host216조합×16셀3456사례의 실제 검증과 Android decoded ARGB 검증은 서로 다른 근거다.

초기 작은 연결성분 제한에 걸린 여자 frame2의23px과 남자 frame2/6의7px씩 천 조각을 독립 검토로 발견해 명시 좌표 주석에 포함했다. 큰 붉은 옆선·mint 목 아래 잔여도 조정했다. 수치 검사를 사용자 시각 승인으로 바꾸지 않는다.

별도로 여자 셀 상단12px의 원래 윗행 신발 누출을 표시용 `renderForDisplay`에서만 가린다. 원본 파일과 raw `render`는 그대로이며 본체 위치·배율은 바꾸지 않는다. 새 Android 검사와 기존 공유 표시 검사의 기대값은 이12px만 구분한다. 색상 raw/display 캐시는 같은8MiB 한도를 공유하고 기본 프레임 캐시는 고정 개수다. 앱 전체 메모리가8MiB라는 의미가 아니다.

## 저장·UI·호환

`AvatarStyle.runningKitColors`는 기존 형태 ID와 별개다. 원본·민트·코랄·블루·퍼플·골드를 지원한다. 누락·손상 JSON은 해당 색상만0으로 복원하고 이름·포인트·보유권을 초기화하지 않는다. 기존58개 아이템 ID/13슬롯/9개 탭·무료 선택·성별·세트/액세서리 규칙은 유지한다.

기존 상의·하의·신발 탭 안에 이름·체크·최소48dp 영역을 가진 평평한 선택 행을 제공한다. 폭·글씨에 따라 줄을 바꾸며 마스크 준비는 IO에서 확인한다. 마스크 오류 시 기본형으로 돌아가고 선택을 비활성화해 재시도한다. 미준비 형태 아이템 선택 저장과 기본형 색상을 구분한다.

기본 Firebase 모드의 색상은 기기 저장 범위다. Google 연결만으로 원본 GPS·지갑·옷장/색상을 다른 기기에 복원하지 않는다. 선택형 HTTP는 strict0..5·nested 부분 PATCH와 서버의 명시 저장 ACK를 사용한다. 구서버422는 지원 안내를 표시하고 세션/프로필/보유권을 초기화하지 않는다. 기존 연결·성별·장비 요청에는 새 필드를 무조건 전송하지 않는다. 새 Rules·키·Secret·DB 스키마 변경은 없다.

독립 코드 검토에서 색 변경과 적립 스냅샷의 경합으로 화면 잔액이 뒤처질 수 있음을 찾아 실제 병합 helper와 회귀2개를 추가했다. 잔액만 조건부 병합하며 최신 이름·옷·보유권은 보존한다. LocalWallet.commit(false)는 성공으로 처리하지 않고 한국어 저장 실패를 안내한다. SharedPreferences 메모리가 실패 시 먼저 갱신될 수 있는 경계는 디스크 내구성과 구분한다.

## 실행 근거와 남은 범위

[버전별 실행 기록](app-review/2026-11-04-kit-colors/README.md)에 JVM81개·debug lint 오류0/경고34·서버43개(기존 경고1)·host 픽셀 검사와 이번 Android 실행별 원문/사진을 기록한다. 코드 읽기 검토를 HTTP 실제 세션 경합이나 운영 서버 실행 성공으로 표시하지 않는다. Native UI fixture와 실제 MainActivity·실제 휴대폰·공개 서명 APK 실행을 구분한다.

실제 휴대폰·Google·운영 두 기기 쓰기·야외 GPS/배터리·사용자 시각 승인은 별도다. 지도 인증/실사용 검증은 이번 범위가 아니다. 기존 MapPane의 main 효과에서 마커가 첫 마스크를 읽는 경우의 작업자 사전 준비, 일시 실패 뒤 마커 generation 갱신은 후속 성능/복구 점검으로 남긴다.

Aseprite의 레이어/프레임 문서와 DESIGN의 awesome-design-md 위계/절제 원칙을 참고했으며 Aseprite 실행·생성 모델로 새 캐릭터 원화 제작은 하지 않았다. 기존 공개0.3.2 APK 출처8eb04d8과 이전0.1.5 출처75c39ca를 새 문서 커밋으로 바꾸지 않는다.

실제 Main 통합 검증은 외부 Android 입력으로 성별/3부위 색상·기기 저장과 실제 그림을 확인한다. 새 Main JUnit harness의 실패/검사시계 관련 프로세스 종료는 보존하며 기존 회귀 검사를 삭제하지 않는다. 외부 입력 결과를 JUnit1개 통과로 합산하지 않는다. 현재 시도 전 데이터 복원과 이전 크래시 직전 원문 미확인은 분리한다. 최종 상태/새 프로세스/정리는 실행 기록의 실제 JSON을 따른다.

외부 입력 최종 검증은 성공했다. 남녀 두 조합과 홈을 포함한5장·실제 프로세스 종료/새PID·재시작 후 색상/그림, 현재 시도 전 데이터/설정 복원을 확인했다. 전용 AVD는 종료했다. 실제 휴대폰·공개 보관키 APK 실행과 사용자 시각 승인은 별도다.
