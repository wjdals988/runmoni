# 런모니 0.10.1-dev

러닝과 옷장의 작은 화면 배치, 미니미 피팅, 런모니 R 아이콘을 다듬은 Android 개발 프리뷰입니다.

- 큰 글씨에서도 거리·시간·페이스와 GPS 상태가 러닝 첫 화면에 들어옵니다. 홈에서 러닝 준비와 날씨 확인을 바로 열 수 있습니다.
- 탐색의 위치와 주변 러너 버튼을 지도 위에 두고, 작은 화면에서도 지도 출처가 읽히도록 조작 메뉴를 정리했습니다. 나 화면에서 러닝 기록으로 바로 이동합니다.
- 옷장에 부위 전체 선택을 추가하고 모자 세 종류의 착용 위치를 맞췄습니다. 기존 미니미 원화를 사용합니다.
- 기록 공유에서 미리보기 아래에서 사진을 추가합니다. 기존 R의 윤곽을 살리고 청록 배경과 작은 크기 가독성을 다듬었습니다.

Android API 29 에뮬레이터에서 화면과 주요 조작을 검증했습니다. 휴대폰 실기기 검증 전 개발 프리뷰입니다. [화면과 아이콘 비교](https://github.com/wjdals988/runmoni/tree/main/docs/app-review/2026-11-28-alignment-refinement)
