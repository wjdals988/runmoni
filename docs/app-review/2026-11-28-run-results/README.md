# 런모니 0.11.0-dev 러닝 결과 검토

API 29 클라우드 에뮬레이터에서 디버그 앱을 게스트로 열어 홈을 확인했다. 새로 설치한 상태의 **최근 7일**은 기록 없음으로 표시된다. [홈 화면](home-main.png)

결과는 거리·러닝 시간·평균 페이스, 구간 선택, 사용자 요청으로 열리는 지도, 기록 관리 순서다. 차트와 표는 같은 구간을 가리킨다. 기록의 러닝 타이머와 전체 경과를 구분한다. 완료 구간의 번호와 시간이 확인되는 경우에 구간 비교를 표시한다.

다음 캡처는 Android의 실제 Compose 화면에 검토용 기록을 넣어 촬영했다.

- 요약 아래에서 빠른 구간과 구간·경로 바로가기를 확인할 수 있다. [결과 첫 화면](run-result-overview-411-fixture.png)
- 선택한 1km의 페이스를 전체 평균 및 직전 구간과 비교할 수 있다. [페이스 분석](run-result-pace-and-laps-411-fixture.png)
- 첫 화면에 세 지표와 공유 버튼을 배치했다. 같은 화면에서 목표와 전체 경과도 확인할 수 있다. [320×520dp·200% 글씨](run-result-320-font2-fixture.png)

거리 또는 시간 목표는 선택한 러닝의 로컬 기록에 저장해 복구와 결과에서 사용한다. 목표를 달성한 뒤에도 기록을 이어갈 수 있다. Google 백업은 날짜·거리·시간과 GPS 측정 수를 요약으로 저장한다.

로컬 JVM 284개가 통과했다. API 29의 결과·홈·목표·기록 흐름 5개와 저장·복구·백그라운드 기록 5개가 통과했다. 직전 1km 비교를 보완한 최종 빌드에서 결과 선택과 큰 글씨 검사 2개를 다시 실행해 확인했다. 백그라운드 기록에는 테스트 위치를 주입했다. 휴대폰의 실제 음성·진동·이어폰·절전 검증은 별도다.
