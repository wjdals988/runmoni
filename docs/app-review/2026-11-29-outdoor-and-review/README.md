## 화면과 동작

- 야외 집중 화면에서 일반 러닝은 거리를, 인터벌은 현재 단계와 남은 시간을 크게 보여준다. GPS 상태는 글자로 구분하고 일시정지와 종료는 하단에 둔다. 집중 화면을 닫아도 러닝은 이어진다. [거리 중심 화면](run-outdoor-distance-320-font2-fixture.png) · [인터벌 화면](run-outdoor-interval-320-font2-fixture.png)
- 완료 기록에서 거리·시간 목표 또는 인터벌을 준비 화면으로 불러온다. 출발은 준비 화면의 기존 시작 버튼으로 한다. 달리기 비교에서 날짜와 시각을 나누고 같은 열의 수치를 오른쪽에 맞춘다. 거리·시간·페이스를 같은 표시 단위로 비교한다. [지난 러닝과 비교](past-run-comparison-320-font2-fixture.png)
- 새 러닝의 1km 경계를 해당 GPS 지점과 함께 저장한다. 차트나 구간표에서 1km를 선택하면 저장한 경로를 강조할 수 있다. 기존 기록은 전체 지도와 구간표를 계속 표시한다. [선택 구간 강조](run-lap-highlight-fixture.png)
- 체감 강도와 한 줄 메모는 각각 선택해 입력할 수 있다. 이 기기의 완료 기록에 저장하며 기록 공유와 백업에는 포함하지 않는다. [메모 입력](run-reflection-editor-320-font2-fixture.png) · [저장한 메모](run-reflection-saved-320-font2-fixture.png)

## frontend-design 점검

- 화면 폭에 따라 20·24·32dp의 바깥 여백과 48dp의 주요 터치 영역을 사용한다. 한눈에 읽는 거리와 시간에 고정폭 숫자를 쓰고 단위를 숫자에 맞춘다.
- 상태 글자를 얹는 트랙 화면은 짙은 청록 표면을 사용한다. 달리기와 회복이 전환될 때 약 150ms 동안 강조선을 움직인다. 동작 줄이기 설정에서는 즉시 전환하고, 초 단위 타이머 갱신에는 강조선 효과를 반복하지 않는다. [공통 디자인 기준](../../../DESIGN.md)

## 첫 후보 검증 범위

- 단위 테스트 300개를 통과했다. API 29 전용 에뮬레이터에서 버전 코드 37을 38로 업데이트하고 MainActivity 홈이 열리는 것을 확인했다.
- 실제 Android 화면에 검토용 기록과 인터벌 시계를 넣어 캡처했다. 320dp·글자 200%에서 두 가지 집중 화면의 수치, GPS 문구와 48dp 하단 조작을 검사했다. 준비 화면으로 복귀할 때 자동 출발하지 않으며, 닫았다 다시 연 기록에도 오래된 클릭이 적용되지 않는다.
- 앱 APK가 같은 상태에서 Android 검사 9개가 통과했다. 처음 9개 중 8개가 통과했고, 인터벌 강조선의 단일 픽셀 색을 찾던 검사를 보완했다. 같은 APK의 재실행에서 중간 프레임·같은 단계에서의 유지·동작 줄이기의 즉시 전환을 확인했다.
- 지도 캡처는 검토용 좌표와 오프라인 타일을 사용했다. 실제 야외 GPS와 온라인 지도, 휴대폰 위젯, 음성·진동은 이 검증 범위에 포함되지 않는다.

## 최종 후보 검증

- 단위 테스트 300개와 API 29 에뮬레이터 검사 19개를 통과했다. 기본 글씨 크기의 360·390·411dp에서 지도 복귀, 홈·러닝의 라이트·다크, 옷장 목록·색상 왕복을 검사했다. 옷장 복귀를 보완한 APK에서 1개와 18개로 나누어 다시 실행했다.
- Android에서 기본 헤어와 새 3종의 남녀 각 8포즈를 렌더했다. 모자 조합과 썸네일에서도 기존 착용 상태와 새 윤곽을 확인했다. 에뮬레이터 종료 후 연결된 AVD가 없는 것을 확인했다.
- 위젯은 Android RemoteViews에서 테마 대비와 종료·저장 조작을 검사했다. 주입한 위치로 백그라운드 기록과 일시정지의 시간 고정을 확인했다. 실제 휴대폰의 화면 잠금·런처, 야외 GPS와 음성·진동은 실기기 확인이 남아 있다.
- 모션과 화면은 개발 APK에서 검사했다. 서명 APK의 버전과 출처는 공개 릴리스 자산을 기준으로 삼는다. [최종 서명 빌드](https://github.com/wjdals988/runmoni/actions/runs/46170090713)
