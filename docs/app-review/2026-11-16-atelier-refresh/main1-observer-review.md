# Main1 관측 실패 보존

첫 실제Main은13장 원본과 남녀 모자/세트·새3종 착용·사진Picker/클린/스탬프 관측 뒤 false로 끝났다. 제품은 저장한 기록 탭을 복원했는데 관측기가 사진 탭 전용 버튼을 찾았다. RunShareScreen의 rememberSaveable tool 및 RunmoniApp의 recordStateHolder를 읽고 확인했다. 해당 wait75초의 실패·raw·원래 parentfalse·13장·전체 복원을 보존한다. 제품 코드·검사·APK를 변경하지 않았다.

재실행 Main2는 실제 사진 탭을 눌러 photo 버튼을 확인한다. 이미 관측한 profile IME/여자 모자/세트 동선을 재실행했다고 부르지 않으며, 남자캡/새3종/사진공유/복원/무료지도와 원래데이터·환경복원을 새로 확인할 계획이다. 공개갤러리4장은 새 Main2가 실제 전체 통과할 때만 새 원본에서 선택한다. 첫 관측 도구 실패를 앱의 초안 소실이나 수정 완료로 바꾸지 않는다.
