# 무료 지도 개선 계획과 검토 경계

frontend-design 스킬과 기존 awesome-design-md 참고/행동 우선 기준을 적용한다. 사용자의 최신 선택은 현재 무료 지도를 개선하는 것이므로 MapLibre12.0.1/OpenFreeMap을 유지한다. Google SDK·키·결제·계정·서버 Rules·새 의존성을 추가하지 않는다.

## 먼저 본 화면과 계획

기존 실제 API29 Native fixture `docs/app-review/2026-11-15-companion/map-online5-native-online-seoul-fixture.png`를 직접 보았다. 노란 간선과 파란 POI 기호가 반복되어 러닝 경로/작은 미니미와 시각적으로 경쟁한다. 과거 실행 화면의 관찰이며 이번 새 실행으로 표시하지 않는다.

6색 역할은 지면 #F5F7F4, 도로 #FFFFFF, 공원 #E0EAD9, 물 #D1E4E8, 글자 #344B53, 경로 #206A75다. 한국어 표기는 기존 Noto Sans/시스템 대체를 유지한다. 실제 지형은 바꾸지 않고 건물·도로·POI 대비를 낮춰 경로와 러너가 먼저 읽히게 한다. 일반 POI는 희미한 계층, 역/교통은 길 찾기 단서로 남긴다. 경로는 흰 외곽선과 진한 청록, 러너 발밑 점은 흰 테두리로 분리한다.

```
지도: 도로/물/공원 → 실제 경로 → 실제 미니미/이름
지도 밖: 출처 + 지도 조작
기존 상세 영역: 위치 상태 + [새로고침] + 내 위치/공유 설정
```

지도 위 카드/버튼/장식 배지를 새로 얹지 않는다. 기존 48dp·font2·지도 높이/스크롤과 정확한 좌표 변환·카메라·source 적용/이미지 prune 경계를 유지한다.

## 반론과 선택

단순히 모든 라벨을 숨기면 공원·만남 장소를 찾기 어렵다. 모든 건물을 같은 강한 색으로 바꾸는 것도 경로를 방해한다. 따라서 지명·교통 단서는 유지하고 알려진 표면/POI 역할만 차분하게 조정한다. provider 데이터가 없는 장소 이름/코스를 만들어 넣지 않는다. 자유로운 고급 스타일링 때문에 Google의 인증/청구 요구를 우회하지 않는다.

배경 위치 조회 실패를 매번 오류로 보여 주는 것은 사용자의 지도 이동을 실패처럼 느끼게 한다. 자동 이동/주기 갱신은 지도·기존 마커·확인 시각을 보존하고 오류 배너/토스트를 만들지 않는다. 수동 새로고침 실패만 기존 지도 밖 상태 영역에 짧게 안내하고 같은 행동으로 재시도하게 한다. 오래된 공개 마커의 기존 freshness/만료 필터를 연장하거나 timestamp를 새로 쓰지 않는다. 다른 UID/로그아웃에서는 기존 마커를 보존하지 않는다.

## 검증 경계

소스/검사와 문서를 작성하되 이 담당자는 빌드·AVD/ADB·네트워크·설치·Git을 실행하지 않는다. 색 대비의 정적 계산과 소스 검사, 새 JVM/Android 검사 소스는 실제 Native 픽셀/조작 실행 성공과 별개다. 실제 새 화면·작은 폭/font2·라벨·경로·교체 미니미·배경 실패/수동 재시도 확인은 Root의 새 입력 실행으로 남긴다. 과거 성공과 합산하지 않는다.

## 반영한 소스와 정적 확인

- MapLibre의 알려진 source-layer 역할만 색을 조정한다. 미지 레이어·도로 폭/필터·교통/철도·지형 좌표는 유지한다. 일반 POI의 아이콘은 낮은 강조, 교통 역할 ID는 더 높은 강조를 쓰며 라벨을 전부 숨기지 않는다. 보행/자전거/트랙 선을 흰색으로 지워 버리지 않고 보조 잉크로 남겼다.
- 경로 폭5/흰 외곽9, 러너 발밑 점5/흰 테두리2.5로 분리했다. 미니미 픽셀·이미지 키·마지막 준비 이미지·runner source Sync 후 prune·평면 건물 정책은 유지했다.
- 지도 밖 상태 줄에 48dp 새로고침을 추가했다. 글씨1.3배부터 상태와 새로고침을 수직으로 나누어 긴 상태 문구가 좁은 열에 몰리지 않게 했다. 기존 지도 위에는 추가 행동이 없다.
- 자동/수동 조회를 분리했고 요청 ticket·계정/세대·화면/viewport가 맞을 때만 결과를 적용한다. 실패에는 marker/checkedAt을 새로 쓰지 않는다. 계정/서버 세대가 달라지거나 미인증이면 이전 조회 목록을 비운다. 공개 위치의 기존45초 freshness 필터는 수정하지 않았다. 오류 로그/좌표/UID를 새로 출력하지 않는다.
- 단색 토큰 계산은 경로/지면5.77:1, 경로/도로6.21:1, 주 글자/지면8.56:1이다. 보조 잉크 #50666D는 지면5.63:1·공원4.89:1·물4.61:1이다. 실제 지도 이미지 위 모든 픽셀/프레임의 대비를 측정한 결과가 아니다.
- 캐시 SDK의 FillLayer/LineLayer/SymbolLayer에 getSourceLayer가 있음을 바이트에서 확인했고 Kotlin lexical delimiter를 검사했다. 컴파일 성공을 뜻하지 않는다.

새 검사 소스는 JVM2개(자동 실패의 비경고/확인시각 보존, 수동 실패의 재시도 문구)와 Android1개(지도 밖 새로고침 재시도·marker/동의 보존)다. 기존 narrow/font matrix에도 새로고침의48dp bounds를 추가했다. 현재 해당 클래스의 소스 메서드는 VectorMapContractTest5개, RunnerDiscoveryUiTest7개다. 실행하지 않았으며 성공 개수로 세지 않는다. Android fixture는 실제 Firebase query나 ViewModel 네트워크를 실행한 결과가 아니다.

실제 수정 범위: `ui/MapLibreMapPane.kt`, `ui/RunnerDiscoveryScreen.kt`, `domain/VectorMapContract.kt`, AppViewModel의 discovery 필드/메서드, 위 두 검사 클래스, `docs/MAP_PROVIDER_OPTIONS.md`, 이 작업 메모다. 계정 담당과 공유 ViewModel의 수정 구역을 조율했다. MapPane/SDK 의존성/Rules/키/결제/타일 호스트·쿼리 수 제한은 바꾸지 않았다.
