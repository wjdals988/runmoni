# 런모니 여백·정렬과 아이콘 개선

기존 기울어진 R은 같은 비율로 4% 키우고 청록 배경의 밝기만 대각선으로 다듬었다. 48px·24px, 원형과 단색을 Android 리소스에서 읽어 한 판에 비교했다. [런처 아이콘 전후](launcher-comparison.png)

API 29 에뮬레이터에서 디버그 앱을 실행하고 게스트로 들어가 홈을 촬영했다. 날씨를 확인할 수 없는 상태에서 현재 위치 날씨 진입과 러닝 준비가 미니미 옆과 바로 아래에 보인다. [홈 화면](home-main.png)

레이스 바이저, 나이트 캡, 트레일 헤드밴드는 남녀 각 8개 포즈에서 머리에 맞췄다. 64×96 나이트 착장은 남녀 두 포즈씩 다시 그린 비교 시안이다. 144dp에서 얼굴과 장비가 더 잘 읽히고 사용자가 선호한 기존 원화를 앱의 기준으로 삼았다. 도트 변경은 이 원화에 맞춘 모자 3종의 피팅이다. [원화와 피팅](../../design/avatars/atelier-v3/README.md) · [64×96 비교](../../design/avatars/atelier-v3/compact-night-comparison.png)

첫 Android 검토에서 200% 글씨의 탐색 지도 출처가 잘렸다. 제목과 버튼의 실측 높이를 반영해 지도를 배치했다. 같은 검토에서 수동 일시정지 검사에 남아 있던 이전 문구를 현재 문구와 동작을 확인하도록 고쳤다. 기존 테스트 기기에 새 APK를 재설치하는 단계가 시간 초과되어 별도 API 29 기기에 새로 설치했다. 이 빌드에서 레이아웃·아이콘 10개와 옷장 검색, 러닝 중단·저장 장애 복구, 공유 조작 등 기존 동작 7개를 확인했다.

탐색 캡처의 출처 이름 줄바꿈을 확인한 뒤 좁고 글씨가 큰 화면에 48dp 지도 조작 아이콘을 썼다. 최종 빌드의 JVM 267개와 탐색·기록 지도 Android 2개가 통과했다. 이 두 Android 검사의 첫 실행은 Compose 관찰 스레드 예외로 중단됐고, 같은 APK 재실행에서 둘 다 통과했다. 휴대폰 검증은 별도다.
