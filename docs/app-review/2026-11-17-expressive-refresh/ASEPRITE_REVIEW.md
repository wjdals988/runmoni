# Aseprite 도트 검토

## 최종 V4 후보 — 강화된 검사와 재검토

V2의 호스트 수용 뒤 실제 Android 기존 검사에서 남자 헤어6의 변경 픽셀이 3개뿐임을 발견해 통합을 거절했다. 허용 임계값을 낮추지 않고 안전한 후두부/정수리 마스크와 연결 하이라이트를 수정했다. V3 일괄 실행은 환경 재연결 뒤 13프로젝트/302PNG만 남아 미완료로 보존했으며 원인과 종료 코드는 확인하지 못했다.

V4는 실제 Aseprite1.3.18.6-dev를 카테고리별로 순차 실행해 13개 종료0 영수증, 39개 편집 프로젝트와 624그림셀+192역할셀을 완성했다. 강화한 독립 검사는 모든624셀에서 변경20픽셀 초과, 원본/손/알파/허용 마스크 보존을 확인했다. 헤어6 남녀16셀 최소151, 남자8셀 최소362픽셀이다. V2와 달라진 런타임 PNG는 남자 헤어6의8개뿐이며 나머지808개는 동일하다.

Root는 V4 원본/헤어3종 비교와112px 연락표를, 독립 동료는80/112/144px 전체와48헤어셀을 직접 확인해 호스트 통합 후보로 수용했다. 작은 전신에서는 머리·볼·이어폰·워치 차이가 미세하다는 한계를 유지한다. 새 헤어는 소재 변형이며 새 커트가 아니다. 수치/내부 시각 검토는 상업 품질 인증·사용자 시각 승인·실제 Android 검증을 대신하지 않는다. [제작4](aseprite-authorship4.json)·[검사4](aseprite-asset-guard4.json)·[독립 시각 검토](PIXEL_V4_PEER_REVIEW.md). 실제 Android 후속 검증은 개별 자료에 기록한다.

## 1차 출력 — 헤어 거절

실제 headless Aseprite의 새39프로젝트·624그림셀+192의복 역할셀을 내보냈다. Root는144px 연락표를, 동료는112/144px와헤어4/5/6·얼굴6·바이저5·세트7·조끼5의전체프레임을직접보았다. 헤어3종의작은크기구별성부족·무작위점무늬로원본의연결명암을흐리는문제를발견해최종반영을보류했다. 점무늬대신모발흐름의넓은연결하이라이트를요청했다. 조끼5는플라스크캡/원근보완또는정직한명칭이필요하다.

바이저/검토세트/조끼의얼굴·체형·접점에뚜렷한회귀를발견하지못한범위를전체39종상업품질승인으로확장하지않는다. 얼굴장식은작아도눈/입/실루엣을구별용으로교체하지않는다.

첫실행직후Lua의고정반사선tint역할해제수정이이뤄져현재저장된Lua를첫실행의고정해시로표시하지않는다. 1차로그·실제이미지는보존하고,후속실행은실행전Lua복사/해시와출력을결합한다. 첫호스트연락표는Android앱스크린샷이아니다.

## 2차 출력 — 내부 통합 후보 수용

실제 headless Aseprite1.3.18.6-dev로39프로젝트·624그림셀/192역할셀을 다시 저장했다. 첫 실행은 헤어 노이즈로 거절했고, 둘째 실행은 실행 전 Lua386d6c518a9383454ab23eb26caa997e133f2628f69bd5be011d4a9134943867와 독립 참조 해시를 고정했다. 원본 f903.../독립 허용 마스크·손·alpha·역할 검사를 통과했다. [제작 해시](aseprite-authorship2.json)·[데이터 검사](aseprite-asset-guard2.json).

Root는 원본/새헤어3종의256px 비교와112px 전체 연락표를 직접 보았다. 독립 동료는 원본 비교·80/112/144px 전체 연락표·새헤어3종의 남녀16포즈를 직접 확인했다. 점무늬를 제거한 연결 하이라이트가 모발 흐름·원본 윤곽/명암을 보존하며 갑작스런 포즈 변화나 얼굴 가림을 발견하지 못해 호스트 통합 후보로 수용했다. 새 커트3개가 아니라 소재 텍스처3개다. 조끼5는 형태에 맞게 ‘듀얼 포켓 조끼’, 헤어6은 ‘백라이트 텍스처’로 명칭을 교정했다.

80/112px 전신에서는 머리·볼·이어폰·워치의 차이가 미세하다. 선택 부위 미리보기로 확대할 수 있지만 모든 아이템이 작은 전신에서 뚜렷하다고 주장하지 않는다. 이번 내부 호스트 수용은 실제 Android 출력·사용자 시각 승인·상업 품질 인증이 아니다. 실제 저장한39개 .aseprite 원본은 docs/design/avatars/v0.9.0/projects에 보존하고 프로그램/제3자 소스는 배포하지 않는다.
