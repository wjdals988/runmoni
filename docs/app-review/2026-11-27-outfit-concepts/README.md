# 미니미 착용 시안 3종

[기본 착용과 새 시안 비교](outfit-comparison.png) · [옷장 크기와 팔 가림 비교](wardrobe-scale.png) · [현재 0.9 옷장 화면](../2026-11-17-expressive-refresh/live6-main-new-technical-set.png)

| 시안 | 주요 디테일 | Aseprite 편집 파일 |
| --- | --- | --- |
| 레이스 | 민트 바이저에 짙은 챙 밑면을 붙이고, 싱글릿의 사선 테이프와 배번으로 유니폼을 구성했다. 여성형은 원본의 소매와 타이츠 실루엣에 같은 디자인을 입혔다. | [레이스](source/race.aseprite) |
| 야간 도심 | 보랏빛 패널 캡과 손목까지 이어지는 셸을 맞췄다. 지퍼 양쪽에 이어지는 가슴 반사 띠를 배치했다. | [야간 도심](source/night.aseprite) |
| 트레일 | 황토색 밴드, 크기가 다른 두 플라스크, 올리브색 수납 조끼로 구성했다. 어두운 바탕에서도 가슴 스트랩과 허벅지 포켓이 보이도록 테두리 명도를 높였다. | [트레일](source/trail.aseprite) |

각 프로젝트에는 남녀의 동일한 두 러닝 포즈에 맞춘 256×384 셀이 들어 있다. 첫 번째는 보폭이 넓은 포즈고 두 번째는 팔이 몸 앞으로 오는 포즈다. 원본 표시 셀은 잠갔으며 모자, 상의, 봉제선, 소매, 하의, 신발 레이어를 열어 조정할 수 있다. 옷장 크기 비교는 좁은 화면의 큰 글씨 모드 96dp 피팅과 64dp 세트 썸네일을 1dp당 1px로 재현했다.

포즈별 좌표로 도트 레이어를 그리고 Ubuntu 패키지의 Aseprite 1.1.6 배치판으로 편집 파일과 PNG를 저장했다. Aseprite 1.3.18.6에서 프로젝트 3개의 레이어와 남녀 태그를 읽었다. 남녀 12개 착용 합성의 보호 손 영역, 눈·입 주변, 의복 외곽을 검사했고 Aseprite PNG와 저장 전 합성이 보이는 픽셀에서 일치했다. [Aseprite 파일 형식](https://github.com/aseprite/aseprite/blob/main/docs/ase-file-specs.md)

이 비교는 코디 선택용이다. 나머지 6개 프레임의 착용 보정, 애니메이션 재생 및 Android 착용 검증은 선택 후 확인할 범위다.
