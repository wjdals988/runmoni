# 런모니 0.12.0-dev 검토

클라우드 Android API 29에서 디버그 앱을 게스트로 열었다. 홈에서 날짜·제목·출발 버튼과 최근 기록 섹션의 왼쪽 선을 맞췄다. 날씨로 이동하는 동작과 러닝 준비를 첫 화면에 둔다. 기존 미니미 원화를 사용한다. [실제 홈 화면](home-main.png)

## frontend-design 점검

- 화면에서 사용할 수 있는 폭을 기준으로 20·24·32dp 바깥 여백을 적용한다. 거리 숫자와 단위는 기준선을 공유하고, 주요 조작에는 48dp 터치 영역을 확보한다.
- 저장이 확인된 러닝의 결과에서 160ms 트랙 체크를 한 번 표시한다. 요약 수치와 공유는 첫 프레임에 나타난다. 동작을 줄이면 미니미는 정지 포즈와 안내를 유지한다.
- 공유 미리보기의 사진 도구에 옅은 반투명 배경을 사용한다. 큰 글씨·좁은 창·고대비 설정에서는 불투명 배경을 쓴다.
- 트랙 표면 `#103338` 위의 글자 `#F2FCF5`, 보조 글자 `#BCD9D8`, 강조 `#D4F781`의 계산 대비는 각각 12.89:1, 9.05:1, 11.22:1이다. [디자인 기준](../../../DESIGN.md)

## 결과와 인터벌 화면

Android의 실제 Compose 화면에 검토용 기록과 인터벌 시계를 넣어 캡처했다.

- 320dp·글자 200%에서 결과의 세 지표와 공유를 먼저 읽는다. 차트에서 비어 있는 1km를 누르면 선택이 바뀌지 않는다. 지난 러닝 한 건을 선택하면 같은 위치에서 거리·시간·페이스를 비교한다. [작은 화면의 결과](result-320-font2-fixture.png) · [지난 러닝 비교](past-run-comparison-320-font2-fixture.png)
- 인터벌 중 회차와 남은 시간을 확인하고 일시정지할 수 있다. 종료한 단계의 실제 시간을 결과에서 확인한다. [회복 중](interval-recovery-320-font2-fixture.png) · [인터벌 단계별 결과](interval-result-320-font2-fixture.png)
- 방금 저장한 결과의 첫 화면 상단에서 트랙 체크가 시작된다. [저장 연출](saved-result-track-cue-fixture.png)
