# 미니미 러닝 코디 2차 시안

[시안 3종과 디테일 확대](outfit-directions.png) · [이전 시안과 비교](outfit-previous-and-current.png) · [옷장 크기와 세트 조합](wardrobe-fit.png)

| 방향 | 새로 손본 부분 | 편집 원본 |
| --- | --- | --- |
| 레이스 | 바이저 띠와 챙 밑면을 따로 그려 머리 접점을 정리했다. 아이보리 싱글릿에 사선 테이프를 넣고 배번에 독립 레이어를 줬다. | [레이스 Aseprite 파일](source/race.aseprite) |
| 야간 도심 | 캡 원단이 접히는 면과 챙을 나눴다. 소매 손목 마감, 지퍼 양옆 반사 띠, 긴 타이츠의 무릎 봉제로 윤곽을 정리했다. | [야간 도심 Aseprite 파일](source/night.aseprite) |
| 트레일 | 밴드에 버클을 넣고, 플라스크가 조끼 주머니에 잠기는 깊이를 나눴다. 몸 옆 메시 포켓과 허벅지 포켓 덮개를 구분했다. | [트레일 Aseprite 파일](source/trail.aseprite) |

각 파일은 남녀별 승인 러닝 포즈 3개씩, 256×384 픽셀 셀 6개를 담고 있다. 승인 원본 포즈 레이어는 잠겨 있다. 모자, 상의, 하의, 신발을 편집할 수 있고 배번·반사 띠·플라스크도 각각 별도 레이어에 담았다. 세트 간 옷을 바꿔 입힌 검토용 합성 2종을 보드에 넣었다. 96dp 피팅과 64dp 목록 보드는 1dp를 1px로 맞춰 비교했다.

포즈별 좌표로 픽셀을 맞춘 뒤 Aseprite 1.1.6 배치판으로 편집 원본을 저장하고 PNG를 내보냈다. Aseprite 1.3.18.6에서 프로젝트 3개의 레이어와 남녀 태그를 다시 읽었다. 18개 Aseprite 출력은 저장 전 합성과 보이는 픽셀이 일치했다. 승인된 얼굴과 손의 보호 영역은 원본과 비교했고, 포켓과 모자의 외곽 확장은 지정 레이어에서 확인했다. 남자 세 번째 포즈에서 이전 손 보호 마스크에 걸려 있던 싱글릿 원단과 흰 봉제선을 재분류해 원래 붉은 조각이 비치던 부분을 정리했다.

시안 선택용 정지 포즈다. 선택 뒤에는 남녀 각 5개 러닝 프레임을 추가로 맞추고 이어지는 동작과 실제 Android 옷장 착용을 검증해야 한다. [이전 기준 시안](../2026-11-27-outfit-concepts/README.md)
