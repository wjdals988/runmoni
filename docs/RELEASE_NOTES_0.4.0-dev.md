# Runmoni0.4.0-dev — 지도·홈 날씨·프로필과 조작 개선

앱 정보와 긴 확인창은 위쪽 닫기를 고정하고, 키보드·큰 글씨·짧은 화면에서 내용과 저장/취소를 조작할 수 있게 정리했습니다. 부모 설정/정보 화면으로 돌아갈 때 스크롤을 유지합니다. 하단 탭·런처·러닝 알림 아이콘의 선과 심볼을 맞췄습니다.

홈 날짜 옆 현재시각과 현위치 주변 예보·옷차림 안내를 추가했습니다. MET Norway 예보이며 현장 실측/대기질/안전 보장은 아닙니다. 위치·예보 조회 실패를 구분하고 이전 값에 현재 권고를 붙이지 않습니다.

탐색은 항상 지도에서 근처 위치를 공유한 러너를 보는 화면입니다. 핀치/드래그로 이동하고 ‘지도 옵션’에서 대체 조작할 수 있습니다. 크루와 소속 파티는 크루 탭에서 찾습니다. 위치 공유는 매회 동의한 성인 자기확인 프로필의 현재 러닝에 한하며 약100m로 반올림합니다. 일시정지/종료/해제/계정·서버 변경 때 중지하고 오프라인 철회 지연 시 공개 읽기는 최장75초 내 만료합니다. 공유 자체는 기본 꺼짐입니다.

프로필 편집을 한곳으로 모으고 온라인 닉네임은 서버 예약으로 중복을 확인합니다. 기존 UID·크루 권한·기록/지갑·보유 아이템과 승인 미니미 원본을 보존합니다. 과거 미예약 이름 전수 중복 해소나 Google 계정 자동 병합은 포함하지 않습니다.

실제 휴대폰 검증 전 개발 프리뷰입니다. 새 Firebase 규칙·색인 게시와 실제 운영 연결은 로컬 demo 검증과 별도입니다. 현재 세션에는 운영 관리 인증이 없으므로 [운영 적용 안내](https://github.com/wjdals988/runmoni/blob/main/docs/DISCOVERY_REFRESH_20261110.md)를 따릅니다. 휴대폰·실제 Google 로그인·야외 GPS/장시간/절전·Android31이상·사용자 시각 승인은 별도 확인이 필요합니다.

기존 보관 키로 서명한 APK만 공개합니다. 2026.10.28 이전 다른 키의 테스트 앱은 덮어쓸 수 없어 기록을 내보낸 뒤 재설치해야 합니다. 이후 같은 키의 개발 버전은 업데이트 설치 대상입니다.
