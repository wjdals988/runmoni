# 런모니 0.2.0-dev — 실기기 검증 전 개발 프리뷰

Android 10 이상에서 검토하는 테스트용 앱입니다. 실제 휴대폰 설치·Google 로그인·야외 GPS·음성 검증은 아직 완료하지 않았습니다. 검증 범위를 정식 운영 완료로 해석하지 않습니다.

- 홈·탐색·러닝·크루·나의 화면 구성과 동선을 전면 변경했습니다. 캐릭터와 러닝 시작, 검색 중심의 모임 목록, 실제 기록을 우선합니다.
- 옷장을 전체 화면으로 넓히고 미리보기를 고정했습니다. 미준비 아이템은 구매·착용할 수 없으며 기존 포인트와 보유 내역은 유지합니다.
- 내 메시지/다른 메시지/공지를 구분하는 채팅 말풍선, 프로필·러닝 옵션을 먼저 보여주는 설정을 적용했습니다.
- 초대코드 없는 크루·파티 방 생성·검색·입장과 크루 없는 독립 파티를 포함합니다. **공용 서버는 아직 연결하지 않았습니다.** 다른 휴대폰과 방을 공유하는 서비스는 이용 준비 중이며 혼자 달리기와 내 기록은 기기에 저장됩니다.
- 러닝 자동 일시정지와 GPS/권한 설정에서 돌아오는 복구 개선을 포함합니다. 지도 SDK 인증·Google 백업·LiveKit 음성은 별도 연결/검증이 필요합니다.
- 상단 설치 버전명·새 버전 레드닷·업데이트 내역·확인 후 다운로드 동선을 유지합니다. 알림 검토 화면의 가상 새 버전은 공개 릴리스가 아닙니다.

0.1.6-dev와 같은 보관된 배포 키를 사용합니다. 0.1.6 설치본은 같은 패키지·서명으로 업데이트할 수 있는 구성이며 실제 휴대폰 업데이트는 미검증입니다. 그보다 오래된 다른 서명 설치본은 중요한 기록을 GPX로 내보낸 뒤 재설치가 필요할 수 있습니다. 개발 프리뷰이므로 실제 기기에서 기록 보존과 동작을 확인해 주세요.

공개 파일의 버전/서명/해시/빌드 출처와 검증 결과는 릴리스 metadata 및 CHANGELOG를 따릅니다. 이전 APK의 sourceRevision은 변경하지 않습니다.
