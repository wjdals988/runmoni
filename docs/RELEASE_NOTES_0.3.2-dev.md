# Runmoni 0.3.2-dev — 기록 복구와 크루 계정 연결

실제 휴대폰 검증 전 개발 프리뷰입니다. 일반 배포의 안정성이나 실제 Google 로그인·운영 Firebase 쓰기 성공을 확인한 버전으로 표시하지 않습니다.

- 러닝 저장 실패 시 같은 기록을 재시도하고, 종료 저장이 끝나기 전 재개·새 러닝을 막습니다.
- 기기 기록 저장·포인트 처리·Google 요약 백업 상태를 분리합니다. 저장 실패에는 하단 재시도를 제공합니다.
- 오래된 GPS 신호를 현재 수신처럼 표시하지 않고 신호 공백 구간을 구분합니다.
- 기존 크루 UID를 유지하는 Google 연결과, 이미 연결된 크루 프로필의 재연결 경로를 추가했습니다. 계정 충돌 시 자동 병합하지 않습니다.
- 큰 글씨와 복구 상태 알림을 보강했습니다. 승인 미니미 원본·남녀 선택·테스트0P·포인트/보유 내역을 유지합니다.

기존0.1.6 이후와 같은 보관 서명키를 사용합니다. 이전 키의 테스트 앱과 업데이트 호환을 보장하지 않습니다. 현재 기기 기록·포인트·옷장은 크루 Google 연결만으로 다른 기기에 복원되지 않습니다. 원화가 준비되지 않은 의상은 선택만 보관하고 승인 기본형을 표시합니다. 새 Firestore Rules 변경은 없습니다.

오프라인 JVM76개, debug lint오류0/경고34와 클라우드 API29/TCG Android 데이터12·UI7·큰 글씨4·로컬demo Firebase SDK1 실행 결과를 기록했습니다. 조건별 반복을 고유 검사 수로 합산하지 않습니다. 실제 휴대폰·Google·다른 기기 복원·운영 쓰기·야외 GPS/배터리는 별도 확인이 필요합니다.
