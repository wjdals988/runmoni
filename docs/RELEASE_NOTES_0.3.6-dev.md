# 런모니 0.3.6-dev — 첫 로그인 선택

스플래시 다음에 Google 로그인 또는 게스트로 시작하는 화면을 추가했습니다. 한 번 선택하면 다음 실행부터 앱으로 바로 들어갑니다. 기존 사용자의 기록과 진행·복구 중인 러닝도 유지합니다.

게스트는 로그인이나 크루 가입 없이 기기의 러닝·기록·미니미 꾸미기를 이용합니다. Google 로그인은 기록 요약 백업 계정 연결에 사용하며 요약 백업은 직접 실행합니다. 러닝 경로·포인트·옷장은 기기에 저장되고 크루 프로필의 연결·복원은 해당 기능에서 별도로 선택합니다.

계정 선택 취소·실패 때 다시 선택할 수 있고, Google 인증을 기다리는 중에도 게스트로 시작할 수 있습니다. 기존 서명키·승인 미니미 원본·기록과 보유 아이템·무료/성별 정책을 유지합니다. 새 Firebase 규칙이나 키 설정은 없습니다.

실제 휴대폰 검증 전 개발 프리뷰입니다. 클라우드 AOSP 에뮬레이터 검증은 실제 Google 로그인·휴대폰·운영 쓰기·Android12이상 시작 화면 실행을 대신하지 않습니다.
