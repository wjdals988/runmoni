# 런모니 0.12.0-dev

- 위치가 준비되면 홈 화면 위젯에서 기본 러닝을 시작할 수 있어요. 넓은 위젯에서 마치고 저장한 뒤 해당 결과를 열 수 있어요.
- 홈·러닝·결과 화면의 여백과 정렬을 맞췄어요. 방금 저장한 결과에는 짧은 트랙 체크가 나타나요. 시스템 모션 설정에 맞춰 미니미 재생을 제어해요.
- 측정이 빠진 1km 구간을 차트에 비워 두고, 직접 고른 지난 러닝과 거리·시간·평균 페이스를 비교할 수 있어요.
- 달리기와 회복 시간을 맞춰 인터벌을 시작하고, 저장된 결과에서 수행한 단계와 시간을 확인할 수 있어요.

계속 사용하던 런모니 배포 키로 서명했습니다. Pixel과 Galaxy의 위젯 시작·저장, 잠금·절전 상태와 실제 음성·진동을 확인하기 위한 후보입니다.
