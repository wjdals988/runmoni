# 런모니 0.3.1-dev — 러닝·일정 중심 UI

**실기기 검증 전 개발 프리뷰입니다.** 실제 휴대폰 설치·업데이트·Google 로그인·운영 두 기기 파티/채팅은 별도 미검증입니다.

- 홈에서 러닝 시작·참가한 다음 파티·최근 기록을 먼저 확인합니다. 오늘의 합계는 기기에 실제 저장된 러닝으로 계산합니다.
- 크루·파티의 큰 카드를 일정·거리·페이스·인원을 비교하는 목록으로 정리했습니다. 크루 안에서 파티를 생성·참가·삭제하는 구조와 기존 권한·뒤로 가기는 유지합니다.
- 옷장의 큰 빈 썸네일과 반복 가격을 줄이고 선택·준비 상태를 구분했습니다. 남녀 기본형과 테스트 기간 전 아이템0P 획득/선택 저장을 유지합니다.
- **미준비 의상은 선택만 저장하고 승인된 기본 미니미를 표시합니다.** 새로운 의복/수영복 그림·런타임 색상 기능의 완성이나 시각적 승인을 뜻하지 않습니다.
- 개인 러닝·포인트·보유권·기존 아이템 ID를 보존합니다. 기존0.1.6/0.2.0/0.2.1/0.3.0과 같은 보관 키를 사용합니다. 이전의 다른 키 설치본은 필요한 기록을 내보낸 뒤 재설치가 필요할 수 있습니다.
- 파티 삭제/계층 권한에는 최신 Firestore 규칙의 운영 게시가 필요합니다. 기존 설정 완료 보고나 공개 목록 읽기 검사를 이번 규칙 적용/운영 쓰기 검증으로 표시하지 않습니다.

앱 화면 검토 사진은 클라우드 Android에서 실행한 debug MainActivity/로컬 HTTP 테스트 데이터입니다. 공개 서명 APK·실제 휴대폰·운영 Firebase 데이터 실행 화면과 구분합니다.
