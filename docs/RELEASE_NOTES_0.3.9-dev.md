# 런모니 0.3.9-dev — 러닝 위젯과 경로 기록

실제 휴대폰 검증 전 개발 프리뷰입니다.

- 홈 화면에 러닝 위젯을 추가해 진행 중 거리·시간을 확인하고 일시정지·재개할 수 있습니다. 종료는 앱에서 확인합니다. 기기·런처에 따라 위젯 추가 방법이 다릅니다.
- 러닝 기록을 별도 페이지로 열고 경로 지도·거리·시간·구간 기록과 GPX 내보내기·요약 백업·삭제 조작을 모았습니다.
- 지도 설정이 없는 환경에서도 OpenStreetMap 배경을 제공합니다. 현재 화면의 타일만 불러오며 실패 시 재시도할 수 있습니다. 저장된 GPS가 없는 과거 기록에는 경로를 만들어 넣지 않습니다.
- 홈과 기록 요약에 민트·짙은 녹색 강조를 더하고 작은 화면·큰 글씨에서 조작 영역을 정리했습니다.
- 기존 기록·포인트·58개 아이템 ID·0P 테스트·성별 전환·승인 미니미 원본·동일 서명키를 유지합니다. 새 Firestore 규칙이나 로그인 설정은 필요하지 않습니다.
- 클라우드 API29의 TEST debug 실행·합성 GPS 검증은 실제 휴대폰·Google 로그인·야외 GPS·장시간 절전/제조사 정책·Android12 이상 실행·사용자 시각 승인과 별개입니다. 공개 서명 APK의 출처와 검증 결과는 릴리스 메타데이터에 기록합니다.
