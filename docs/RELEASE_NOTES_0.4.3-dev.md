# Runmoni 0.4.3-dev — 정사각형 공유·위젯·지도 개선

러닝 결과에서 사진·기록·본인 미니미로 공유 이미지를 만듭니다. 기본은 1:1이며 4:5와 9:16도 지원합니다. 색상·문구·기록 배치·날짜·닉네임, 사진의 이동·확대와 미니미 위치·크기를 조절하고 PNG로 저장하거나 Android 공유 화면으로 보냅니다. 자동 게시하지 않습니다.

위젯은 밝은 바탕에 거리·시간·속도의 위계를 정리하고 필요한 조작에 집중했습니다. 지도 위에 떠 있던 버튼은 지도 아래 ‘지도 조작’ 메뉴로 모았습니다. 드래그·핀치와 접근성 조작, 지도 출처는 유지합니다.

원본 사진, 기기 기록·포인트·보유 아이템을 수정하지 않으며 GPS 경로와 원본 사진의 EXIF 메타데이터는 공유 PNG에 넣지 않습니다. 기존 지도 제공자와 개인정보 공유 정책을 유지합니다.

실제 휴대폰 검증 전 개발 프리뷰입니다. 같은 보관 서명키를 사용합니다. 휴대폰의 사진 선택·갤러리·SNS 전송, Google 로그인·운영 연결과 네이버 지도 인증은 별도 확인이 필요합니다.
