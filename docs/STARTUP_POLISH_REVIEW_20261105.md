## 상호 검토

- consumer_copy_ui: 반복 제목/설명·빈 상태·맥락별 검색을 검토했다. 마지막 통합 검토에서 '최대50개' 및 '다운로드 화면'의 실제 동작 불일치를 지적해 수정했다.
- settings_copy_ui: 계정·Google 요약 백업/크루 프로필·익명 연결 해제·점검 상태를 검토하고 설정과 앱 정보를 정리했다.
- ux_startup_review: 별도 스플래시 화면·저장 상태·애니메이션 비활성화를 검토했다. native SplashScreenView와 Jetpack provider의 차이를 발견해 `.view` 없이 native view를 직접 animate하도록 수정했다. 시작 바 색상도 명시했다.

필수 안내는 삭제하지 않았다. 러닝 경로·포인트·옷장은 Google 요약 백업으로 복원되지 않으며, 크루 계정 연결/복원도 별도다. 위치 공유의 성인 동의·45초 만료·명시적 선택, 저장 실패/복구, 업데이트 확인 후 다운로드를 유지한다. 승인 원본·기존36개 표시/미준비22개·58개 ID·무료/성별·보유권/포인트는 변경하지 않는다.
