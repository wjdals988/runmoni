# 런모니 0.13.0-dev

- 야외 집중 화면에서 달린 거리와 GPS 상태를 빠르게 읽을 수 있어요. 인터벌은 현재 단계·남은 시간과 바로 다음 단계가 먼저 보여요.
- 지난 기록에서 `이 훈련 다시 준비`를 누르면 거리·시간 목표와 인터벌을 다시 불러올 수 있어요.
- 두 러닝의 거리·시간·평균 페이스 차이를 확인할 수 있어요. 새로 기록한 1km에 위치 경계가 저장되면 구간표나 차트에서 해당 경로를 열고 강조할 수 있어요.
- 결과에 체감 강도와 한 줄 메모를 선택해 남길 수 있어요. 메모는 이 기기에 저장돼요.
- 위치 사용이 준비된 상태에서 홈 화면 위젯으로 러닝을 시작하고 일시정지할 수 있어요. 넓은 위젯에서는 종료를 확인하고 기록을 저장할 수 있어요.
- 앱과 위젯의 라이트·다크 색 배치를 다듬었어요. 구간 지도에서 같은 1km 기록으로 돌아가고, 옷장 목록에서 착용한 아이템의 색상에 바로 이동할 수 있어요.
- 기본 헤어에 더해 슬림 쇼트·사이드 파트·로우 번의 윤곽을 새로 그렸어요. 옷장에서는 각 헤어의 모양을 모자 없이 비교할 수 있어요.

런모니의 기존 배포 키로 서명한 Android 개발 프리뷰입니다. 위젯 동작과 야외 시인성, 실제 음성·진동은 휴대폰 환경에 따라 별도 확인이 필요합니다.
