# Runmoni 0.8.0-dev

실기기 검증 전 개발 프리뷰입니다. 기존 보관 키를 사용합니다.

- 모자·세트 의복의 도트 디테일을 다듬고 메시 저지·리브 크루삭스·패널 러닝화 3종을 추가했습니다. 옷장은 현재 착용 모습과 부위별 미리보기 목록으로 고릅니다.
- 공유 이미지는 전체 사진 위에 미니미와 기록을 배치합니다. 기본 1:1과 4:5·9:16, 클린·기록 강조·스탬프, 글씨 톤과 기록·미니미의 독립 위치 조절을 지원합니다.
- Google 계정 연결 후 완료한 러닝 요약을 자동 백업하며 대기·완료·재시도·충돌 상태를 구분합니다. 경로·포인트·옷장은 기기에 남습니다.
- 무료 벡터 지도의 색·경로와 자동 갱신 안내를 정리하고 앱·알림 아이콘을 바꿨습니다.

승인 원본 얼굴·체형·8프레임과 기존 58개 아이템 ID prefix·13슬롯·9탭·보유 정보·무료 설정을 보존합니다. 전체 ID는 61개이며 모든 ID의 원화 준비 완료를 뜻하지 않습니다. Aseprite 소재는 실제 로컬 배치 편집으로 제작했고, 곰·골든은 같은 몸의 후드·운동복 표현입니다.

휴대폰·실제 Google 로그인/자동 백업·운영 쓰기·SNS 전달·야외 GPS/절전·공개 서명 APK 실행과 사용자 시각 승인은 별도 확인 대상입니다. 검토 화면은 클라우드 Android의 합성 기록·사진을 사용한 TEST debug 화면이며, 공개 서명 APK 실행 검증으로 표시하지 않습니다.
